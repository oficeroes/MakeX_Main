# 第 3 课：板载资源编程

> **学习目标：** 掌握 Novapi 主控板自带硬件的编程方法——陀螺仪姿态检测、加速度与角速度读取、震动检测、以及系统计时器的使用。

---

## 1. 板载资源总览

Novapi 主控板内置以下资源，无需外接任何模块即可使用：

| 资源       | 函数簇                                     | 数据类型 |
| ---------- | ------------------------------------------ | -------- |
| 系统计时器 | `novapi.timer()` / `novapi.reset_timer()`  | 秒       |
| 姿态角     | `get_pitch()` / `get_roll()` / `get_yaw()` | 度       |
| 加速度     | `get_acceleration(axis)`                   | g        |
| 角速度     | `get_gyroscope(axis)`                      | °/s      |
| 震动检测   | `is_shaked()` / `set_shake_threshold()`    | 布尔     |
| 角度重置   | `reset_rotation(axis)`                     | 无       |

> ⚠️ 所有板载功能都通过 `import novapi` 导入后直接调用，不需要实例化。如果代码中忘记 `import novapi`，这些函数将不可用。

## 2. 系统计时器

计时器从系统上电开始计时，也可以手动复位。

### API 参考

```python
novapi.timer()        # 返回从复位后经过的秒数（float）
novapi.reset_timer()  # 将计时器归零
```

### 典型应用：定时触发

```python
import novapi
import time

novapi.reset_timer()
INTERVAL = 5  # 每 5 秒触发一次

while True:
    if novapi.timer() > INTERVAL:
        print("5 秒到了！执行定时任务...")
        novapi.reset_timer()  # 重置计时器

    # 这里放你的主循环逻辑
    time.sleep(0.01)
```

### 典型应用：非阻塞延时

```python
import novapi

novapi.reset_timer()

while True:
    # 替代 time.sleep(3) 的非阻塞写法
    if novapi.timer() > 3:
        print("3 秒后执行，但主循环没有卡住")
        novapi.reset_timer()
    # 其他逻辑可以继续运行
```

## 3. 陀螺仪姿态角

板载六轴 IMU 提供三个姿态角。注意偏航角（Yaw）有累积误差。

```
         Z (Yaw - 偏航)
         │
         │    /
         │   /
         │  /
         │ /
         └──────────── Y (Roll - 翻滚)
        /
       /
      /
     X (Pitch - 俯仰)
```

### API 参考

```python
novapi.get_pitch()   # 俯仰角 (X轴旋转): -180° ~ 180°
novapi.get_roll()    # 翻滚角 (Y轴旋转): -180° ~ 180°
novapi.get_yaw()     # 偏航角 (Z轴旋转): -32768° ~ 32767°（有累积误差！）
```

### 示例：用姿态角控制

```python
import novapi
import time

while True:
    pitch = novapi.get_pitch()
    roll = novapi.get_roll()
    yaw = novapi.get_yaw()

    print("俯仰:%.1f  翻滚:%.1f  偏航:%.1f" % (pitch, roll, yaw))

    # 根据俯仰角判断方向
    if pitch > 45:
        print("  主控板向前倾斜 > 45°")
    elif pitch < -45:
        print("  主控板向后倾斜 > 45°")

    time.sleep(0.1)
```

## 4. 加速度与角速度

### API 参考

```python
novapi.get_acceleration(axis)   # axis: "x", "y", "z"，返回 g 值
novapi.get_gyroscope(axis)      # axis: "x", "y", "z"，返回 °/s，范围 -500~500
```

### 示例：读取三轴加速度

```python
import novapi
import time

while True:
    ax = novapi.get_acceleration("x")
    ay = novapi.get_acceleration("y")
    az = novapi.get_acceleration("z")

    print("加速度 X:%.2fg  Y:%.2fg  Z:%.2fg" % (ax, ay, az))
    time.sleep(0.1)
```

### 示例：读取三轴角速度

```python
import novapi
import time

while True:
    gx = novapi.get_gyroscope("x")
    gy = novapi.get_gyroscope("y")
    gz = novapi.get_gyroscope("z")

    print("角速度 X:%.1f°/s  Y:%.1f°/s  Z:%.1f°/s" % (gx, gy, gz))
    time.sleep(0.1)
```

### 示例：自由落体检测

```python
import novapi
import time

# 静止时 Z 轴加速度 ≈ 1g（重力），自由落体时 ≈ 0g
FREE_FALL_THRESHOLD = 0.3  # 低于此值认为是自由落体

while True:
    az = abs(novapi.get_acceleration("z"))

    if az < FREE_FALL_THRESHOLD:
        print("⚠️ 检测到自由落体！")

    time.sleep(0.05)
```

## 5. 震动检测

### API 参考

```python
novapi.set_shake_threshold(threshold)   # threshold: 0~100，默认 50，0=关闭
novapi.is_shaked()                      # 返回 True/False
```

### 示例：敲击触发

```python
import novapi
import time

novapi.set_shake_threshold(60)  # 适当提高阈值避免误触发

print("敲击主控板来触发事件...")

while True:
    if novapi.is_shaked():
        print("🔔 检测到震动！")
        # 在这里执行震动触发的动作
        time.sleep(0.3)  # 消抖延时

    time.sleep(0.05)
```

## 6. 角度重置

### API 参考

```python
novapi.reset_rotation(axis)   # axis: "x", "y", "z", "all"
```

### 示例：累积转圈计数

```python
import novapi
import time

novapi.reset_rotation("all")

while True:
    yaw = novapi.get_yaw()

    # 每转一圈（360°）重置一次
    if abs(yaw) >= 360:
        print("转完一圈！当前累计角度: %.1f°" % yaw)
        novapi.reset_rotation("z")

    time.sleep(0.05)
```

## 7. 综合示例：体感遥控器

用板载陀螺仪的姿态角作为遥控信号，可用于后续控制小车：

```python
"""
体感遥控器
用 Novapi 的倾斜角度生成前进/后退/转向信号
"""
import novapi
import time

# 配置
DEAD_ZONE = 10       # 死区范围（度），防止微小抖动
MAX_ANGLE = 60       # 最大有效角度
MAX_POWER = 100      # 最大输出动力

def tilt_to_power(angle):
    """将角度映射为 -100~100 的动力值"""
    if abs(angle) < DEAD_ZONE:
        return 0
    # 限幅
    if angle > MAX_ANGLE:
        angle = MAX_ANGLE
    elif angle < -MAX_ANGLE:
        angle = -MAX_ANGLE
    # 线性映射
    return int(angle / MAX_ANGLE * MAX_POWER)

while True:
    pitch = novapi.get_pitch()   # 前后倾斜 → 控制前进/后退
    roll = novapi.get_roll()     # 左右倾斜 → 控制转向

    forward_power = tilt_to_power(pitch)
    turn_power = tilt_to_power(roll)

    # 差速计算（后续连接电机时使用）
    L_power = forward_power + turn_power
    R_power = forward_power - turn_power

    print("前进:%d  转向:%d  →  左轮:%d  右轮:%d" %
          (forward_power, turn_power, L_power, R_power))

    time.sleep(0.05)
```
