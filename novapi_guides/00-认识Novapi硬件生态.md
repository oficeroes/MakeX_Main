# 第 0 课：认识 Novapi 硬件生态

> **学习目标：** 了解 Novapi 主控板的定位、硬件架构、可连接的模块种类，以及整个 Neuron 电子积木生态系统的组成。

---

## 1. Novapi 是什么？

**Novapi** 是 Makeblock 旗下 **神经元（Neuron）系列** 电子积木平台的核心主控板。它运行 **MicroPython** 固件，支持用 Python 语言编程来控制各种电子积木模块。

```
┌────────────────────────────────────────────────┐
│                  Novapi 主控板                    │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐  │
│  │ 6轴陀螺仪 │  │ WiFi/BLE │  │ MicroPython   │  │
│  │ 加速度计  │  │  无线通信  │  │  运行时环境    │  │
│  └──────────┘  └──────────┘  └──────────────┘  │
│                                                  │
│  外接端口:  M1 M2 M3 M4  PORT1 PORT2 PORT3 PORT4 │
└────────────────────────────────────────────────┘
```

---

## 2. 硬件端口布局

Novapi 主控板上有两类外接端口：

| 端口类型       | 标识              | 数量 | 用途                             |
| -------------- | ----------------- | ---- | -------------------------------- |
| **电机端口**   | `M1` ~ `M4`       | 4 个 | 连接编码电机、智能舵机等执行器   |
| **传感器端口** | `PORT1` ~ `PORT4` | 4 个 | 连接各种传感器模块               |
| **USB 口**     | —                 | 1 个 | 连接电脑，用于上传代码和串口通信 |

> ⚠️ **注意：** 传感器和电机的端口不能混用。编码电机/智能舵机必须接在 M 口，传感器模块必须接在 PORT 口。

---

## 3. 板载硬件资源

Novapi 主控板自带以下硬件（无需外接模块即可使用）：

| 硬件                              | 功能                             | 编程方式                                  |
| --------------------------------- | -------------------------------- | ----------------------------------------- |
| **6 轴 IMU**（陀螺仪 + 加速度计） | 检测姿态角、加速度、角速度、震动 | `import novapi` 直接调用                  |
| **系统计时器**                    | 精确计时（秒）                   | `novapi.timer()` / `novapi.reset_timer()` |
| **WiFi / BLE**                    | 无线通信                         | WiFi 模块、蓝牙手柄配对                   |

## 5. 模块的物理连接方式

每个外接模块通过 **RJ25 接口**（类似电话线的 6 针接头）串联在端口上。

```
  [主控板 PORT1 口]
       │
  ┌────┴────┐
  │ 传感器模块1 │  ← INDEX1（端口链上的第1个模块）
  └────┬────┘
       │
  ┌────┴────┐
  │ 传感器模块2 │  ← INDEX2（端口链上的第2个模块）
  └────┬────┘
       │
      ... 可继续串联
```

> **关键概念：** 同一个端口上可以串联多个模块，通过 `INDEX` 区分：
>
> - `"INDEX1"` — 第一个模块
> - `"INDEX2"` — 第二个模块

## 6. 编程模型概述

Novapi 的编程遵循统一的模式：

```
┌─────────────────┐
│  1. import 导入  │  import novapi
│                 │  from mbuild.xxx import xxx_class
├─────────────────┤
│  2. 初始化模块   │  __motor = encoder_motor_class("M1", "INDEX1")
├─────────────────┤
│  3. 主循环运行   │  while True:
│                 │      读取传感器 → 处理逻辑 → 控制执行器
│                 │      time.sleep(0.01)
└─────────────────┘
```

**两类 API 的区别：**

| 类型         | 导入方式                           | 调用方式       | 示例                    |
| ------------ | ---------------------------------- | -------------- | ----------------------- |
| **板载功能** | `import novapi`                    | 直接调用函数   | `novapi.get_pitch()`    |
| **外接模块** | `from mbuild.xxx import xxx_class` | 先实例化再调用 | `__motor.set_power(50)` |

| 项目类型       | 需要的模块                                      |

| 姿态检测云台   | 智能舵机×2 + 板载陀螺仪                         |
| 颜色分拣机     | 编码电机（传送带）+ 智能舵机（推杆）+ RGB传感器 |
