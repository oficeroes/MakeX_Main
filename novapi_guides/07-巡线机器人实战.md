# 第 7 课：巡线机器人实战

> **学习目标：** 综合运用编码电机和双路 RGB 传感器，从零搭建一台完整的巡线机器人，并理解 PID 巡线的基本原理和调参方法。

## 1. 项目概述

本项目将搭建一台**双轮差速巡线机器人**，它能自动跟踪地面上的黑色线条行驶。

```
  ┌──────────────────────────────┐
  │         巡线机器人            │
  │                              │
  │   [RGB1] [RGB2]  ← 双探头    │
  │      ↓     ↓               │
  │  ┌──────────────┐           │
  │  │   Novapi     │           │
  │  │   主控板      │           │
  │  └──────┬───────┘           │
  │    M1   │   M2              │
  │   [左轮]   [右轮]            │
  │                              │
  │  ← ← ← 黑色轨道线 ← ← ←     │
  └──────────────────────────────┘
```

### 硬件清单

| 硬件            | 数量 | 连接端口               |
| --------------- | ---- | ---------------------- |
| Novapi 主控板   | 1    | —                      |
| 编码电机        | 2    | M1（左轮）、M2（右轮） |
| 双路 RGB 传感器 | 1    | PORT1, INDEX1          |
| 底盘 + 车轮     | 1 套 | —                      |
| 电池            | 1    | 电源口                 |

## 2. 巡线原理

```
俯视图：
          ← 小车前进方向 →

            === 黑线 ===

   RGB1 ●          ● RGB2
   (左探头)       (右探头)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 白色背景
```

- 两个探头在白色背景上检测黑色轨道线
- 当探头在**黑线上方** → 光强低 → "在线上"
- 当探头在**白色背景上方** → 光强高 → "在轨道上"

### 状态与修正策略

| 状态   | RGB1   | RGB2   | 车身位置    | 修正动作                     |
| ------ | ------ | ------ | ----------- | ---------------------------- |
| `"00"` | 线上   | 线上   | ✅ 居中     | 直行，不需修正               |
| `"01"` | 线上   | 轨道上 | ↙️ 偏右     | 左轮减速/右轮加速 → 左转修正 |
| `"10"` | 轨道上 | 线上   | ↗️ 偏左     | 右轮减速/左轮加速 → 右转修正 |
| `"11"` | 轨道上 | 轨道上 | ❌ 完全离线 | 按上次方向继续转或停止       |

## 3. 版本一：简单状态机巡线

适合初学者理解巡线逻辑的最简实现。

```python
"""
巡线机器人 v1 — 简单状态机
根据双探头状态直接切换运动方向
"""
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.encoder_motor import encoder_motor_class

# ==== 初始化 ====
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# ==== 参数 ====
BASE_SPEED = 40        # 直行速度
TURN_SPEED = 30        # 转弯速度

print("巡线机器人 v1 启动！")

while True:
    if __rgb.is_state("00"):
        # 双探头在线上 — 直行
        __motor_L.set_power(BASE_SPEED)
        __motor_R.set_power(BASE_SPEED)

    elif __rgb.is_state("01"):
        # 只有左探头在线上 — 车身偏右，左转修正
        __motor_L.set_power(-TURN_SPEED)   # 左轮反转
        __motor_R.set_power(TURN_SPEED)    # 右轮正转

    elif __rgb.is_state("10"):
        # 只有右探头在线上 — 车身偏左，右转修正
        __motor_L.set_power(TURN_SPEED)    # 左轮正转
        __motor_R.set_power(-TURN_SPEED)   # 右轮反转

    elif __rgb.is_state("11"):
        # 双探头离线 — 小幅度搜索
        __motor_L.set_power(TURN_SPEED // 2)
        __motor_R.set_power(-TURN_SPEED // 2)

    time.sleep(0.01)
```

> ⚠️ v1 的缺点：只有直行和原地旋转两种模式，运行不够平滑，转弯时速度突变大。

## 4. 版本二：比例差速巡线（推荐）

使用 `get_offset_track_value()` 和 `get_motor_diff_speed()` 实现平滑的比例控制。

```python
"""
巡线机器人 v2 — 比例差速控制
平滑转弯，适合中低速巡线
"""
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.encoder_motor import encoder_motor_class

# ==== 初始化 ====
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# ==== 可调参数 ====
BASE_SPEED = 50        # 基础速度 (0~100)
KP = 0.5               # 比例系数 (0.1~1.0)
LOOP_DELAY = 0.01      # 循环周期（秒）

# 配置传感器
__rgb.set_motor_diff_speed_kp(KP)

print("巡线机器人 v2 启动！")
print("基础速度: %d, KP: %.2f" % (BASE_SPEED, KP))

while True:
    # 传感器自动计算差速修正值
    diff = __rgb.get_motor_diff_speed()

    # 左右轮 = 基础速度 ± 修正值
    L_power = BASE_SPEED + diff
    R_power = BASE_SPEED - diff

    # 安全限幅
    L_power = max(-100, min(100, L_power))
    R_power = max(-100, min(100, R_power))

    __motor_L.set_power(L_power)
    __motor_R.set_power(R_power)

    time.sleep(LOOP_DELAY)
```

## 5. 版本三：带避障的巡线机器人

在巡线基础上增加激光测距模块，遇到障碍物自动停车。

```python
"""
巡线机器人 v3 — 巡线 + 避障
巡线行驶，前方出现障碍物时自动停止
"""
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.ranging_sensor import ranging_sensor_class
from mbuild.encoder_motor import encoder_motor_class

# ==== 初始化 ====
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
__ranger = ranging_sensor_class("PORT2", "INDEX1")
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# ==== 参数 ====
BASE_SPEED = 50
KP = 0.5
STOP_DISTANCE = 15      # 触发停车的距离（cm）
LOOP_DELAY = 0.01

__rgb.set_motor_diff_speed_kp(KP)

print("巡线机器人 v3（带避障）启动！")

while True:
    distance = __ranger.get_distance()

    # 优先级 1：避障
    if distance < STOP_DISTANCE:
        print("⚠️ 障碍物距离: %.1f cm — 停止！" % distance)
        __motor_L.set_power(0)
        __motor_R.set_power(0)
    else:
        # 优先级 2：巡线
        diff = __rgb.get_motor_diff_speed()
        L_power = max(-100, min(100, BASE_SPEED + diff))
        R_power = max(-100, min(100, BASE_SPEED - diff))
        __motor_L.set_power(L_power)
        __motor_R.set_power(R_power)

    time.sleep(LOOP_DELAY)
```

## 6. 版本四：带陀螺仪辅助的进阶巡线

用板载陀螺仪的偏航角辅助判断大弯，防止跑出轨道。

```python
"""
巡线机器人 v4 — 陀螺仪辅助巡线
RGB 传感器 + 陀螺仪双保险，防止急弯跑飞
"""
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.encoder_motor import encoder_motor_class

# ==== 初始化 ====
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# ==== 参数 ====
BASE_SPEED = 50
KP = 0.5
MAX_YAW_CHANGE = 30   # 允许的最大偏航变化（度/秒）
LOOP_DELAY = 0.01

__rgb.set_motor_diff_speed_kp(KP)
novapi.reset_rotation("z")  # 重置偏航角
last_yaw = 0

print("巡线机器人 v4（陀螺仪辅助）启动！")

while True:
    # 读取当前偏航角
    yaw = novapi.get_yaw()
    yaw_change = abs(yaw - last_yaw)
    last_yaw = yaw

    # RGB 巡线差速
    diff = __rgb.get_motor_diff_speed()

    # 陀螺仪辅助：如果偏航变化过大，说明在急弯，降低速度
    if yaw_change > MAX_YAW_CHANGE:
        current_speed = BASE_SPEED * 0.5  # 急弯减速 50%
        print("急弯检测！减速至 %d" % current_speed)
    else:
        current_speed = BASE_SPEED

    L_power = max(-100, min(100, current_speed + diff))
    R_power = max(-100, min(100, current_speed - diff))

    __motor_L.set_power(L_power)
    __motor_R.set_power(R_power)

    time.sleep(LOOP_DELAY)
```

## 7. 调参指南

### KP（比例系数）调优

```
KP 太小 → 转弯太慢，跟不上弯道 → 冲出轨道
KP 太大 → 转弯过度，车身左右摇摆 → S 形前进
KP 适中 → 平滑跟随轨道

调参步骤：
1. 从 KP=0.3 开始
2. 如果直道正常但弯道冲出 → 增大 KP（每次 +0.1）
3. 如果车身左右摇摆 → 减小 KP（每次 -0.1）
4. 找到刚好不摇摆的最大 KP 值
```

### BASE_SPEED（基础速度）调优

```
速度越快 → 惯性越大 → 需要更大的 KP 来修正
速度越慢 → 更稳定但比赛时间更长

建议：从 30 开始测试，逐渐增加到不跑飞的最大速度
```

### 探头安装位置

```
           ← 前进方向 →

   RGB1 ●───────────● RGB2
         ← 间距 →
             │
          前轮轴
             │
         ← 前瞻距离 →

- 探头间距：通常 15~25mm（根据轨道线宽调整）
- 前瞻距离：探头离轮轴越远，预判越早，但过远会导致转弯过早
```

## 8. 常见问题

| 问题               | 可能原因                   | 解决方法                                     |
| ------------------ | -------------------------- | -------------------------------------------- |
| 直道也左右摇摆     | KP 太大                    | 减小 KP 到 0.2~0.3                           |
| 弯道直接冲出       | KP 太小 或 速度太快        | 增大 KP 或降低速度                           |
| 一直往一个方向偏   | 左右轮速度不一致           | 检查机械安装或给某个轮加偏置补偿             |
| 十字路口乱转       | 双探头同时看到黑线         | 增加直行优先逻辑，或使用三探头               |
| 传感器识别不到黑线 | 环境光线太强或轨道颜色太浅 | 用黑色电工胶带做轨道，调整 `set_led_color()` |
