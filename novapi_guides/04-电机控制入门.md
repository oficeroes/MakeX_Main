> **学习目标：** 掌握所有电机/舵机类模块的编程方法——编码电机的闭环与开环控制、智能舵机的位置与速度控制、以及动力扩展板的多通道电机/电磁阀控制。

## 1. 电机模块总览

Novapi 可控制三类执行器，都接在 **M 端口**（M1~M4）：

| 模块           | 导入路径                                               | 控制方式                       |
| -------------- | ------------------------------------------------------ | ------------------------------ |
| **编码电机**   | `from mbuild.encoder_motor import encoder_motor_class` | 位置闭环 / 速度闭环 / 开环动力 |
| **智能舵机**   | `from mbuild.smartservo import smartservo_class`       | 位置控制 / 动力控制 + 状态反馈 |
| **动力扩展板** | `from mbuild import power_expand_board`                | 多通道直流/无刷电机 + 电磁阀   |

> ⚠️ **重要的硬件约束：**
>
> - 编码电机和智能舵机必须连接在 **M 端口**（M1~M4）
> - 每个 M 端口可串联多个模块，通过 `INDEX1`、`INDEX2` 区分
> - 动力扩展板不需要指定 M 端口，它通过 `"DC1"~"DC8"` 和 `"BL1"~"BL2"` 区分通道

## 2. 编码电机（Encoder Motor）

编码电机是最常用的动力模块，支持 180 编码电机和 36 堆叠无刷电机。它内置编码器，可实现位置和速度的闭环控制。

### 初始化

```python
from mbuild.encoder_motor import encoder_motor_class

# 创建电机实例：(M端口, INDEX序号)
__motor = encoder_motor_class("M1", "INDEX1")
```

### API 完整参考

| 方法                       | 参数                     | 说明                                                 |
| -------------------------- | ------------------------ | ---------------------------------------------------- |
| `set_power(pwm)`           | pwm: **-100~100**        | **开环控制**：直接设置 PWM 占空比                    |
| `set_speed(speed)`         | speed: rpm（不限）       | **速度闭环**：以指定转速运行，电机会尽力达到目标速度 |
| `move_to(position, speed)` | position: 度, speed: rpm | **位置闭环**：转动到指定的**绝对角度**               |
| `move(position, speed)`    | position: 度, speed: rpm | **位置闭环**：按**相对角度**转动（正=正转，负=反转） |
| `get_value(type)`          | `"angle"` 或 `"speed"`   | 获取当前位置（度）或当前速度（rpm）                  |

### 控制模式对比

```
┌──────────────────────────────────────────────────┐
│                                                    │
│  set_power(50)  →  [电机] → 50% 占空比旋转         │
│  开环：不关心实际转速，只管给多少电                  │
│                                                    │
│  set_speed(100) →  [编码器反馈] → [PID] → [电机]    │
│  速度闭环：自动调节 PWM 以维持 100rpm               │
│                                                    │
│  move_to(360,50) → [编码器计数] → [PID] → [电机]    │
│  位置闭环：精确转到 360° 位置并停下                  │
│                                                    │
└──────────────────────────────────────────────────┘
```

### 示例 1：基础运动控制

```python
import novapi
import time
from mbuild.encoder_motor import encoder_motor_class

__motor = encoder_motor_class("M1", "INDEX1")

# --- 开环控制 ---
__motor.set_power(50)      # 50% 动力正转
time.sleep(2)
__motor.set_power(-50)     # 50% 动力反转
time.sleep(2)
__motor.set_power(0)       # 停止
time.sleep(1)

# --- 速度闭环 ---
__motor.set_speed(100)     # 100 rpm 正转
time.sleep(2)
__motor.set_speed(-100)    # 100 rpm 反转
time.sleep(2)
__motor.set_speed(0)       # 停止

# --- 位置闭环 ---
__motor.move_to(360, 100)  # 转到绝对角度 360°
time.sleep(2)
__motor.move(-360, 100)    # 相对反转 360°
time.sleep(3)
```

### 示例 2：读取电机状态

```python
import novapi
import time
from mbuild.encoder_motor import encoder_motor_class

__motor = encoder_motor_class("M1", "INDEX1")

__motor.set_power(50)
time.sleep(1)

# 读取当前状态
current_angle = __motor.get_value("angle")
current_speed = __motor.get_value("speed")

print("当前角度: %d°" % current_angle)
print("当前速度: %d rpm" % current_speed)
```

### 示例 3：双电机差速底盘

```python
"""
双轮差速底盘控制
左轮接 M1，右轮接 M2
"""
import novapi
import time
from mbuild.encoder_motor import encoder_motor_class

__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

def chassis_control(forward, turn):
    """
    底盘控制函数
    forward: 前进动力 -100~100
    turn:    转向动力 -100~100
    """
    L_power = forward + turn
    R_power = forward - turn

    # 限幅到 -100~100
    L_power = max(-100, min(100, L_power))
    R_power = max(-100, min(100, R_power))

    __motor_L.set_power(L_power)
    __motor_R.set_power(R_power)

# --- 测试各种运动 ---
# 前进
chassis_control(50, 0)
time.sleep(2)

# 后退
chassis_control(-50, 0)
time.sleep(2)

# 原地右转
chassis_control(0, 50)
time.sleep(1)

# 停止
chassis_control(0, 0)
```

## 3. 智能舵机（Smart Servo）

智能舵机支持位置精确控制，并提供电流、电压、速度、角度、温度五维状态反馈。

### 初始化

```python
from mbuild.smartservo import smartservo_class

__servo = smartservo_class("M3", "INDEX1")
```

### API 完整参考

| 方法                       | 参数                                                                | 说明                   |
| -------------------------- | ------------------------------------------------------------------- | ---------------------- |
| `set_zero()`               | 无                                                                  | 设置当前位置为角度零点 |
| `move_to(position, speed)` | position: 度(-2147483648~2147483647), speed: 1~50 rpm               | 转到**绝对角度**       |
| `move(position, speed)`    | position: 度, speed: 1~50 rpm                                       | 转到**相对角度**       |
| `set_power(pwm)`           | pwm: -100~100                                                       | 开环动力控制           |
| `get_value(type)`          | `"current"` / `"voltage"` / `"speed"` / `"angle"` / `"temperature"` | 获取状态反馈           |

### 示例：舵机扫描 + 状态监控

```python
import novapi
import time
from mbuild.smartservo import smartservo_class

__servo = smartservo_class("M3", "INDEX1")

# 先校准零点
__servo.set_zero()
time.sleep(0.5)

while True:
    # 扫描 0° → 180° → 0°
    __servo.move_to(0, 30)
    time.sleep(2)
    __servo.move_to(180, 30)
    time.sleep(2)

    # 读取状态
    angle = __servo.get_value("angle")
    speed = __servo.get_value("speed")
    current = __servo.get_value("current")
    voltage = __servo.get_value("voltage")
    temp = __servo.get_value("temperature")

    print("-" * 40)
    print("角度: %.1f°" % angle)
    print("速度: %.1f rpm" % speed)
    print("电流: %.2f A" % current)
    print("电压: %.2f V" % voltage)
    print("温度: %.1f°C" % temp)
```

## 4. 动力扩展板（Power Expand Board）

动力扩展板可以同时控制多达 8 路直流电机（或电磁阀）和 2 路无刷电机。

### 导入（无需端口）

```python
from mbuild import power_expand_board
# 直接调用函数，不需要实例化
```

### API 完整参考

| 方法                 | 参数                      | 说明         |
| -------------------- | ------------------------- | ------------ |
| `set_power(ch, pwm)` | ch: 通道名, pwm: -100~100 | 设置通道动力 |
| `stop(ch)`           | ch: 通道名 或 `"ALL"`     | 停止指定通道 |

### 通道名称速查表

| 通道类型          | 通道名            | 数量 | 用途                                   |
| ----------------- | ----------------- | ---- | -------------------------------------- |
| 直流电机 / 电磁阀 | `"DC1"` ~ `"DC8"` | 8 路 | 直流电机或电磁阀                       |
| 无刷电机          | `"BL1"` ~ `"BL2"` | 2 路 | 无刷电机（使用 `set_power` 和 `stop`） |
| 全部停止          | `"ALL"`           | —    | 停止所有通道                           |

> 💡 **电磁阀控制技巧：** 电磁阀也接在 DC 通道上，通过 `set_power` 控制：
>
> - `set_power("DC1", 100)` → 电磁阀**通电**（吸合）
> - `set_power("DC1", 0)` → 电磁阀**断电**（释放）

### 示例：多电机协同控制

```python
import novapi
import time
from mbuild import power_expand_board

# 所有直流电机全速正转
for ch in ["DC1", "DC2", "DC3", "DC4"]:
    power_expand_board.set_power(ch, 100)

# 无刷电机半速
power_expand_board.set_power("BL1", 50)

time.sleep(2)

# 全部停止
power_expand_board.stop("ALL")
time.sleep(1)

# 电磁阀动作
power_expand_board.set_power("DC1", 100)  # 通电
time.sleep(1)
power_expand_board.set_power("DC1", 0)    # 断电
```

## 5. 电机控制模式选择指南

| 场景                   | 推荐方法               | 原因                     |
| ---------------------- | ---------------------- | ------------------------ |
| 竞速前进/后退          | `set_power()`          | 开环简单直接，响应快     |
| 需要恒定速度爬坡       | `set_speed()`          | 闭环自动补偿负载变化     |
| 机械臂/转盘精确定位    | `move_to()` / `move()` | 位置闭环确保精度         |
| 舵机做武器/弹射        | `set_power()`          | 快速响应，不需要位置精度 |
| 舵机做机械臂关节       | `move_to()`            | 需要角度精确控制         |
| 电磁阀控制气缸         | `set_power(100/0)`     | 只需通断电两态           |
| 无刷电机（通过扩展板） | `set_power()`          | 扩展板只支持开环控制     |

## 6. 常见问题

**Q: `set_power(0)` 是停止还是刹车？**
A: `set_power(0)` 相当于自由滑行，电机不会主动刹车。如需刹车，可以用 `set_speed(0)`（速度闭环下会主动刹车）或短时间给反向动力。

**Q: 编码电机的 `move_to()` 到达目标后会自动停止吗？**
A: 是的，`move_to()` 到达目标角度后电机会自动保持在该位置（内部 PID 锁定）。

**Q: 动力扩展板的通道号如何对应物理端口？**
A: 动力扩展板有独立的 8 路 DC 和 2 路 BL 通道，不占用主控板的 M 端口。需要参考扩展板的丝印标注来接线。
