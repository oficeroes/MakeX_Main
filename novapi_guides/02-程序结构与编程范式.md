## 1. 核心编程范式

每个 Novapi 程序都遵循一个统一的 **三段式结构**：

```
┌──────────────────────────────────────────────────┐
│                  Novapi 程序模板                    │
│                                                    │
│  # === 第一段：导入模块 ===                         │
│  import novapi        # 板载功能                    │
│  import time           # 标准库                     │
│  from mbuild.xxx import xxx_class  # 外接模块      │
│                                                    │
│  # === 第二段：初始化外设 ===                       │
│  __motor = encoder_motor_class("M1", "INDEX1")     │
│  __sensor = dual_rgb_sensor_class("PORT1", "INDEX1")│
│                                                    │
│  # === 第三段：主循环 ===                           │
│  while True:                                       │
│      读取传感器 → 处理逻辑 → 控制执行器              │
│      time.sleep(0.01)                              │
└──────────────────────────────────────────────────┘
```

---

## 2. 两类 API 的深入理解

Novapi 有两类编程接口，它们的调用方式完全不同。理解这个区别是编程的基础。

### 类型一：板载功能 API（无实例）

板载硬件通过 `import novapi` 后 **直接调用函数**，无需创建对象。

| 函数                            | 说明             | 返回值          |
| ------------------------------- | ---------------- | --------------- |
| `novapi.timer()`                | 获取系统运行时间 | 秒（float）     |
| `novapi.reset_timer()`          | 复位计时器       | 无              |
| `novapi.get_pitch()`            | 获取俯仰角       | -180~180 度     |
| `novapi.get_roll()`             | 获取翻滚角       | -180~180 度     |
| `novapi.get_yaw()`              | 获取偏航角       | -32768~32767 度 |
| `novapi.get_acceleration(axis)` | 获取加速度       | g（float）      |
| `novapi.get_gyroscope(axis)`    | 获取角速度       | °/s             |
| `novapi.is_shaked()`            | 检测是否被晃动   | True/False      |
| `novapi.set_shake_threshold(n)` | 设置震动阈值     | 无 (n: 0~100)   |
| `novapi.reset_rotation(axis)`   | 重置角度积分     | 无              |

**使用模式：**

```python
import novapi

# 板载函数直接调用，不需要实例化
angle = novapi.get_pitch()         # ✅ 正确

# ❌ 错误！板载函数不需要创建对象
# gyro = novapi.gyro_sensor()
# gyro.get_pitch()
```

---

### 类型二：外接模块 API（需实例化）

外接模块需要通过 `from mbuild.xxx import xxx_class` 导入类，然后 **创建实例**，再调用方法。

**通用初始化模板：**

```python
from mbuild.<模块名> import <类名>

# 创建实例：(端口名, 接头序号)
__<变量名> = <类名>("<端口>", "<INDEX>")
```

**完整的端口与 INDEX 参考表：**

| 端口类别   | 可用端口名                                 | INDEX 序号             |
| ---------- | ------------------------------------------ | ---------------------- |
| 电机端口   | `"M1"`, `"M2"`, `"M3"`, `"M4"`             | `"INDEX1"`, `"INDEX2"` |
| 传感器端口 | `"PORT1"`, `"PORT2"`, `"PORT3"`, `"PORT4"` | `"INDEX1"`, `"INDEX2"` |

**每种外接模块的导入和初始化方式：**

```python
# 编码电机
from mbuild.encoder_motor import encoder_motor_class
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# 智能舵机
from mbuild.smartservo import smartservo_class
__servo = smartservo_class("M3", "INDEX1")

# 激光测距
from mbuild.ranging_sensor import ranging_sensor_class
__ranger = ranging_sensor_class("PORT1", "INDEX1")

# 双路 RGB 传感器
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")

# 遥控手柄（无需端口参数，通过蓝牙连接）
from mbuild import gamepad
# 直接使用 gamepad.xxx()，不需要实例化

# 电源管理模块（无需端口参数）
from mbuild import power_manage_module
# 直接使用 power_manage_module.xxx()，不需要实例化

# 动力扩展板（无需端口参数）
from mbuild import power_expand_board
# 直接使用 power_expand_board.xxx()，不需要实例化
```

> 💡 **记忆规律：**
>
> - 需要 `xxx_class("端口", "INDEX")` 的模块：编码电机、智能舵机、激光测距、RGB 传感器
> - 直接导入 `from mbuild import xxx` 即可使用的：遥控手柄、电源管理、动力扩展板

## 3. 变量命名约定

Novapi 代码中通常使用 **双下划线前缀 `__`** 命名模块实例，表示这是全局硬件对象：

```python
# ✅ 推荐命名风格
__motor_left  = encoder_motor_class("M1", "INDEX1")
__motor_right = encoder_motor_class("M2", "INDEX1")
__servo_arm   = smartservo_class("M3", "INDEX1")
__rgb_sensor  = dual_rgb_sensor_class("PORT1", "INDEX1")
__ranger      = ranging_sensor_class("PORT2", "INDEX1")
```

> 📌 这不是 Python 的强制规则，而是 Novapi 社区的编程习惯。`__` 前缀可避免与其他变量名冲突。

## 4. 主循环模式详解

机器人程序的核心是 **读取 → 决策 → 执行** 的循环：

```python
import novapi
import time
from mbuild.encoder_motor import encoder_motor_class

# 初始化
__motor = encoder_motor_class("M1", "INDEX1")

while True:
    # 步骤 1：读取传感器数据
    pitch = novapi.get_pitch()        # 读取板载陀螺仪
    timer_val = novapi.timer()       # 读取系统时间

    # 步骤 2：处理逻辑（决策）
    if pitch > 30:
        power = 80                    # 前倾 → 加速
    elif pitch < -30:
        power = -80                   # 后倾 → 反转
    else:
        power = 0                     # 水平 → 停止

    # 步骤 3：控制执行器
    __motor.set_power(power)

    # 步骤 4：循环延时（避免 CPU 100%）
    time.sleep(0.01)                  # 10ms 周期
```

> ⚠️ **关键：** `time.sleep()` 很重要！如果不加延时，主循环会以 CPU 极限速度运行，可能导致通信阻塞或电机响应异常。典型值为 `0.01`（10ms = 100Hz）到 `0.05`（50ms = 20Hz）。

## 5. 程序组织的最佳实践

### 5.1 初始化区域放在最前面

```python
# ============ 导入 ============
import novapi
import time
from mbuild.encoder_motor import encoder_motor_class
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class

# ============ 全局常量 ============
BASE_SPEED = 50
KP = 0.5
LOOP_DELAY = 0.01

# ============ 硬件初始化 ============
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")

# ============ 初始配置 ============
__rgb.set_motor_diff_speed_kp(KP)
novapi.reset_timer()

# ============ 主循环 ============
while True:
    # 读取
    diff = __rgb.get_motor_diff_speed()
    # 决策
    L_power = BASE_SPEED + diff
    R_power = BASE_SPEED - diff
    # 执行
    __motor_L.set_power(L_power)
    __motor_R.set_power(R_power)
    time.sleep(LOOP_DELAY)
```

### 5.2 用常量化魔法数字

```python
# ❌ 不好的写法：魔法数字散落各处
__motor.move_to(360, 20)
time.sleep(4)
__motor.move(-360, 20)

# ✅ 好的写法：常量集中管理
TARGET_ANGLE = 360
SPEED = 20
WAIT_TIME = 4

__motor.move_to(TARGET_ANGLE, SPEED)
time.sleep(WAIT_TIME)
__motor.move(-TARGET_ANGLE, SPEED)
```

### 5.3 模块对象全局化

```python
# ✅ 推荐：模块实例在文件顶部创建，全局可访问
__motor = encoder_motor_class("M1", "INDEX1")

def do_something():
    __motor.set_power(50)  # 直接使用

# ❌ 不推荐：在函数内部创建（每次调用都重新初始化）
def do_something_bad():
    motor = encoder_motor_class("M1", "INDEX1")
    motor.set_power(50)
```
