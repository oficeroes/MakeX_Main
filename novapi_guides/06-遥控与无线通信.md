## 1. 遥控手柄（Gamepad）

遥控手柄通过**蓝牙**与 Novapi 主控板无线连接，提供 2 个摇杆和 16 个按键的输入。

### 导入（无需端口和初始化）

```python
from mbuild import gamepad
# 直接使用，不需要实例化，也不需要指定端口
```

---

### 1.1 摇杆 API

| 方法                        | 参数                              | 返回值     | 方向约定           |
| --------------------------- | --------------------------------- | ---------- | ------------------ |
| `gamepad.get_joystick(pos)` | `"Lx"` / `"Ly"` / `"Rx"` / `"Ry"` | -100 ~ 100 | 左正右负、上正下负 |

```
      左摇杆              右摇杆
   Ly: -100(下)        Ry: -100(下)
        │                    │
Lx:-100 ─┼─ Lx:+100   Rx:-100 ─┼─ Rx:+100
   (左)  │   (右)      (左)  │   (右)
        │                    │
   Ly: +100(上)        Ry: +100(上)
```

### 1.2 按键 API

| 方法                             | 返回值           | 说明               |
| -------------------------------- | ---------------- | ------------------ |
| `gamepad.is_key_pressed(button)` | `True` / `False` | 判断按键是否被按下 |

### 按键名称完整列表

| 类别         | 按键名                             | 说明                          |
| ------------ | ---------------------------------- | ----------------------------- |
| **方向键**   | `"Up"` `"Down"` `"Left"` `"Right"` | 十字方向键                    |
| **数字键**   | `"N1"` `"N2"` `"N3"` `"N4"`        | 数字按钮 1~4                  |
| **肩键**     | `"L1"` `"L2"` `"R1"` `"R2"`        | 左右肩键（常用作武器/功能键） |
| **功能键**   | `"Start"` `"Select"`               | 开始 / 选择                   |
| **摇杆按下** | `"L_Thumb"` `"R_Thumb"`            | 按下左右摇杆                  |

---

### 1.3 示例 1：全按键读取

```python
import novapi
import time
from mbuild import gamepad

while True:
    time.sleep(0.05)

    # --- 摇杆值 ---
    Lx = gamepad.get_joystick("Lx")
    Ly = gamepad.get_joystick("Ly")
    Rx = gamepad.get_joystick("Rx")
    Ry = gamepad.get_joystick("Ry")

    # 只有摇杆不在中位时才打印
    if abs(Lx) > 10 or abs(Ly) > 10 or abs(Rx) > 10 or abs(Ry) > 10:
        print("摇杆: Lx=%d Ly=%d Rx=%d Ry=%d" % (Lx, Ly, Rx, Ry))

    # --- 按键检测 ---
    buttons = ["Up", "Down", "Left", "Right",
               "N1", "N2", "N3", "N4",
               "L1", "L2", "R1", "R2",
               "Start", "Select", "L_Thumb", "R_Thumb"]

    for btn in buttons:
        if gamepad.is_key_pressed(btn):
            print("按键按下: %s" % btn)
```

### 1.4 示例 2：遥控底盘控制

这是最常见的遥控模式——左摇杆控制前进/后退，右摇杆控制转向：

```python
"""
遥控底盘
左摇杆上下 → 前进/后退
右摇杆左右 → 转向
"""
import novapi
import time
from mbuild import gamepad
from mbuild.encoder_motor import encoder_motor_class

__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

DEAD_ZONE = 10  # 摇杆死区

while True:
    # 读取摇杆
    Ly = gamepad.get_joystick("Ly")  # 左摇杆上下 → 前进后退
    Rx = gamepad.get_joystick("Rx")  # 右摇杆左右 → 转向

    # 死区处理：小于死区的值视为 0
    if abs(Ly) < DEAD_ZONE:
        Ly = 0
    if abs(Rx) < DEAD_ZONE:
        Rx = 0

    # 混合为左右轮动力
    L_power = Ly + Rx
    R_power = Ly - Rx

    # 限幅
    L_power = max(-100, min(100, L_power))
    R_power = max(-100, min(100, R_power))

    __motor_L.set_power(L_power)
    __motor_R.set_power(R_power)

    time.sleep(0.02)
```

### 1.5 示例 3：遥控武器控制

用肩键控制舵机武器：

```python
"""
遥控战车：底盘 + 武器
R1/R2 → 武器正转/反转
L1 → 武器急停
"""
import novapi
import time
from mbuild import gamepad
from mbuild.encoder_motor import encoder_motor_class
from mbuild.smartservo import smartservo_class

__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")
__weapon = smartservo_class("M3", "INDEX1")

while True:
    # --- 底盘：左摇杆 ---
    Ly = gamepad.get_joystick("Ly")
    Rx = gamepad.get_joystick("Rx")

    if abs(Ly) < 10: Ly = 0
    if abs(Rx) < 10: Rx = 0

    L_power = max(-100, min(100, Ly + Rx))
    R_power = max(-100, min(100, Ly - Rx))
    __motor_L.set_power(L_power)
    __motor_R.set_power(R_power)

    # --- 武器：肩键 ---
    if gamepad.is_key_pressed("R1"):
        __weapon.set_power(100)     # 武器正转（攻击）
    elif gamepad.is_key_pressed("R2"):
        __weapon.set_power(-100)    # 武器反转（收回）
    elif gamepad.is_key_pressed("L1"):
        __weapon.set_power(0)       # 急停
    # 不按任何键时保持当前状态（不主动停止）

    time.sleep(0.02)
```

## 2. MQTT 物联网通信

Novapi 主控内置 MQTT 客户端，可通过 WiFi 连接 MQTT 服务器（Broker）进行远程数据收发。

> 📌 MQTT 是一种轻量级的发布/订阅（Pub/Sub）消息协议，特别适合 IoT 设备。基本概念：
>
> - **Broker（服务器）**：消息中转中心
> - **Topic（主题）**：消息的分类标签，如 `"robot/sensor/temp"`
> - **Publish（发布）**：向某个 Topic 发送消息
> - **Subscribe（订阅）**：监听某个 Topic，收到消息时自动回调

### 依赖库

```python
from mqtt import MQTTClient
# 或使用简化版
from simple_mqtt import MQTTClient
```

> ⚠️ MQTT 需要 WiFi 连接，使用前需先配置 WiFi。本课专注于 MQTT 协议本身。

---

### 示例：MQTT 远程传感器上报

```python
"""
MQTT 远程上报示例
将激光测距数据定时发布到 MQTT Broker
"""
import novapi
import time
from mqtt import MQTTClient
from mbuild.ranging_sensor import ranging_sensor_class

# WiFi 配置（需要根据实际网络修改）
WIFI_SSID = "your_wifi_name"
WIFI_PASSWORD = "your_wifi_password"

# MQTT 配置
MQTT_BROKER = "test.mosquitto.org"  # 公共测试 Broker
MQTT_PORT = 1883
MQTT_TOPIC = "novapi/robot1/distance"
CLIENT_ID = "novapi_robot1"

# 传感器
__ranger = ranging_sensor_class("PORT1", "INDEX1")

# 连接 WiFi（伪代码，实际需调用 WiFi 模块）
# wifi.connect(WIFI_SSID, WIFI_PASSWORD)

# 连接 MQTT
client = MQTTClient(CLIENT_ID, MQTT_BROKER, port=MQTT_PORT)
client.connect()
print("MQTT 已连接")

while True:
    distance = __ranger.get_distance()

    # 发布距离数据
    client.publish(MQTT_TOPIC, str(distance))
    print("发布: %s → %.1f cm" % (MQTT_TOPIC, distance))

    time.sleep(1)
```

### 示例：MQTT 远程控制

```python
"""
MQTT 远程控制示例
通过订阅 MQTT 主题接收远程指令控制电机
"""
import novapi
import time
from mqtt import MQTTClient
from mbuild.encoder_motor import encoder_motor_class

MQTT_BROKER = "test.mosquitto.org"
MQTT_PORT = 1883
CMD_TOPIC = "novapi/robot1/command"

__motor = encoder_motor_class("M1", "INDEX1")

# MQTT 消息回调
def on_message(topic, msg):
    """收到 MQTT 消息时调用"""
    command = msg.decode("utf-8")
    print("收到指令: %s" % command)

    if command == "forward":
        __motor.set_power(50)
    elif command == "backward":
        __motor.set_power(-50)
    elif command == "stop":
        __motor.set_power(0)
    elif command.startswith("speed:"):
        speed = int(command.split(":")[1])
        __motor.set_power(speed)

# 连接 MQTT
client = MQTTClient("novapi_robot1", MQTT_BROKER, port=MQTT_PORT)
client.set_callback(on_message)
client.connect()
client.subscribe(CMD_TOPIC)
print("已订阅: %s，等待指令..." % CMD_TOPIC)

while True:
    # MQTT 消息通过回调自动处理
    # 这里可以放其他传感器读取逻辑
    client.check_msg()  # 检查是否有新消息
    time.sleep(0.1)
```

## 3. 遥控手柄 vs MQTT 对比

| 特性     | 遥控手柄       | MQTT                     |
| -------- | -------------- | ------------------------ |
| 通信方式 | 蓝牙直连       | WiFi + 服务器中转        |
| 通信距离 | 10m 以内       | 理论上全球可达           |
| 延迟     | 极低（几毫秒） | 较高（几十~几百毫秒）    |
| 适用场景 | 实时遥控竞技   | 远程监控、数据采集、IoT  |
| 需要外设 | 只需手柄       | 需要 WiFi 和 MQTT Broker |
| 上手难度 | ⭐ 简单        | ⭐⭐⭐ 中等              |
