## 🎯 学习建议

### 对人类开发者

1. **按顺序学习**：每课都有前置依赖，跳课可能导致理解困难
2. **动手实践**：每课的代码示例都可以直接运行，建议边看边试
3. **先测试再组装**：第 8 课提供了分模块测试方案，一个模块调通再接入下一个
4. **善用 API 速查**：需要快速查阅某个函数的参数时，参考 [Novapi 编程指南（完整 API 参考）](../Novapi编程指南.md)

### 对 AI Agent

1. **第 0-2 课是地基**：必须理解硬件端口布局、API 类型区分、程序三段式结构
2. **第 2 课的程序骨架**：生成任何 Novapi 代码时，以此为模板
3. **第 7-8 课是参考实现**：当用户请求"搭建一个机器人"时，参考这两课的完整代码
4. **生成代码时的检查清单**：
   - ☑ 板载功能用 `import novapi` 直接调用
   - ☑ 外接模块用 `from mbuild.xxx import xxx_class` 并实例化
   - ☑ 电机接 M 端口，传感器接 PORT 端口
   - ☑ 主循环中有 `time.sleep()`
   - ☑ 电机的 `set_power` 值在 -100~100 范围内
   - ☑ 变量命名使用 `__` 前缀
