## 2. 激光测距模块（Ranging Sensor）

基于 ToF（飞行时间）原理的激光测距传感器，用于检测前方障碍物距离。

### 初始化

```python
from mbuild.ranging_sensor import ranging_sensor_class

__ranger = ranging_sensor_class("PORT1", "INDEX1")
```

### API

| 方法             | 返回值        | 说明               |
| ---------------- | ------------- | ------------------ |
| `get_distance()` | float（厘米） | 获取前方障碍物距离 |

### 关键特性

- **有效测量范围：** 2cm ~ 200cm
- **盲区：** 2cm 以内的物体检测不准确
- **超量程：** 距离 > 200cm 或 < 2cm 时，返回值为 200

### 示例 1：基础距离读取

```python
import novapi
import time
from mbuild.ranging_sensor import ranging_sensor_class

__ranger = ranging_sensor_class("PORT1", "INDEX1")

while True:
    distance = __ranger.get_distance()
    print("前方距离: %.1f cm" % distance)
    time.sleep(0.2)
```

### 示例 2：分级报警

```python
import novapi
import time
from mbuild.ranging_sensor import ranging_sensor_class

__ranger = ranging_sensor_class("PORT1", "INDEX1")

DANGER_ZONE = 20    # 危险距离（cm）
WARNING_ZONE = 50   # 警告距离（cm）

while True:
    d = __ranger.get_distance()

    if d <= DANGER_ZONE:
        print("🔴 危险！距离仅 %.1f cm" % d)
    elif d <= WARNING_ZONE:
        print("🟡 警告！距离 %.1f cm" % d)
    else:
        print("🟢 安全，距离 %.1f cm" % d)

    time.sleep(0.2)
```

## 3. 双路 RGB 传感器（Dual RGB Sensor）

这是 Novapi 最核心的传感器，具备**巡线**和**颜色识别**两大功能。它有两个独立的探头（RGB1 和 RGB2）。

### 初始化

```python
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class

__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
```

### 3.1 颜色识别功能

#### 颜色识别 API

| 方法                  | 参数                 | 说明                   |
| --------------------- | -------------------- | ---------------------- |
| `get_intensity(ch)`   | `"RGB1"` 或 `"RGB2"` | 获取探头光强（0~255）  |
| `is_color(ch, color)` | ch, color（见下表）  | 判断是否检测到指定颜色 |

#### 支持的颜色列表

| 颜色名     | 中文 |
| ---------- | ---- |
| `"white"`  | 白色 |
| `"red"`    | 红色 |
| `"yellow"` | 黄色 |
| `"green"`  | 绿色 |
| `"cyan"`   | 青色 |
| `"blue"`   | 蓝色 |
| `"purple"` | 紫色 |
| `"black"`  | 黑色 |

#### 颜色识别示例

```python
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class

__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")

while True:
    # 检查 RGB1 探头
    if __rgb.is_color("RGB1", "red"):
        print("RGB1: 检测到红色")
    elif __rgb.is_color("RGB1", "green"):
        print("RGB1: 检测到绿色")
    elif __rgb.is_color("RGB1", "blue"):
        print("RGB1: 检测到蓝色")

    # 检查 RGB2 探头
    if __rgb.is_color("RGB2", "red"):
        print("RGB2: 检测到红色")

    # 读取光强值
    intensity1 = __rgb.get_intensity("RGB1")
    intensity2 = __rgb.get_intensity("RGB2")
    print("  光强 — RGB1:%d  RGB2:%d" % (intensity1, intensity2))

    time.sleep(0.2)
```

### 3.2 巡线功能

巡线功能的原理是两个探头检测黑线/白背景，通过计算偏离量来调整电机差速。

#### 巡线 API

| 方法                          | 参数                              | 说明                             |
| ----------------------------- | --------------------------------- | -------------------------------- |
| `is_on_track(ch)`             | `"RGB1"` / `"RGB2"`               | 探头是否在轨道（黑线）上         |
| `is_on_background(ch)`        | `"RGB1"` / `"RGB2"`               | 探头是否在背景（白色区域）上     |
| `is_state(state)`             | `"00"` / `"01"` / `"10"` / `"11"` | 判断双探头组合状态               |
| `get_offset_track_value()`    | 无                                | 获取偏离轨道的偏差值（-100~100） |
| `set_motor_diff_speed_kp(kp)` | kp: 0~1                           | 设置 PD 差速系数                 |
| `get_motor_diff_speed()`      | 无                                | 获取电机差速值（= offset × kp）  |
| `set_led_color(color)`        | `"red"` `"green"` `"blue"`        | 设置巡线辅助 LED 颜色            |

#### 状态码详解

```
  探头1    探头2
  (RGB1)  (RGB2)

  "00" = 线上    线上    ← 理想状态，直线前进
  "01" = 线上    轨道上  ← 车偏右了，需要左转
  "10" = 轨道上  线上    ← 车偏左了，需要右转
  "11" = 轨道上  轨道上  ← 完全偏离轨道

  "轨道上"指探头在白色背景上，"线上"指探头在黑色轨道上
```

#### 示例 1：状态检测

```python
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class

__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")

while True:
    if __rgb.is_state("00"):
        print("状态: 00 — 双探头均在线上 → 直行")
    elif __rgb.is_state("01"):
        print("状态: 01 — 只有 RGB1 在线上 → 左转修正")
    elif __rgb.is_state("10"):
        print("状态: 10 — 只有 RGB2 在线上 → 右转修正")
    elif __rgb.is_state("11"):
        print("状态: 11 — 双探头均离线 → 寻找轨道")

    time.sleep(0.1)
```

#### 示例 2：单探头检测

```python
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class

__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")

while True:
    track1 = __rgb.is_on_track("RGB1")
    track2 = __rgb.is_on_track("RGB2")

    print("RGB1在线上:%s  RGB2在线上:%s" %
          ("是" if track1 else "否", "是" if track2 else "否"))
    time.sleep(0.2)
```

#### 示例 3：自动差速巡线

```python
"""
差速巡线程序
使用 get_motor_diff_speed() 自动计算修正量
左轮接 M1，右轮接 M2，RGB 传感器接 PORT1
"""
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.encoder_motor import encoder_motor_class

# 初始化
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# 配置
BASE_SPEED = 50       # 基础速度
__rgb.set_motor_diff_speed_kp(0.5)  # 差速系数
# 系数越大转弯越剧烈，系数越小转弯越平缓

while True:
    # 获取自动计算的差速修正值
    diff = __rgb.get_motor_diff_speed()

    # 基础速度 ± 修正值 = 左右轮速度
    __motor_L.set_power(BASE_SPEED + diff)
    __motor_R.set_power(BASE_SPEED - diff)

    time.sleep(0.01)  # 100Hz 控制频率
```

> 💡 **差速系数 KP 调参指南：**
>
> - KP = 0.3：平缓修正，适合高速直道
> - KP = 0.5：中等修正，适合一般弯道
> - KP = 0.8：剧烈修正，适合急弯，但可能震荡
> - KP = 1.0：最大修正，可能导致车身左右摇摆

## 4. 电源管理模块（Power Manage Module）

用于竞赛场景，判断当前是自动赛还是手动赛模式。

### 导入（无需端口）

```python
from mbuild import power_manage_module
```

### API

| 方法                                 | 返回值           | 说明                                      |
| ------------------------------------ | ---------------- | ----------------------------------------- |
| `power_manage_module.is_auto_mode()` | `True` / `False` | `True` = 自动赛模式, `False` = 手动赛模式 |

### 示例

```python
import novapi
import time
from mbuild import power_manage_module

while True:
    if power_manage_module.is_auto_mode():
        # 自动赛：运行预设的自动程序
        print("自动赛模式：执行自动程序...")
    else:
        # 手动赛：等待遥控信号
        print("手动赛模式：等待遥控指令...")
    time.sleep(1)
```

## 5. 传感器数据整合框架

在实际机器人中，通常需要同时读取多个传感器：

```python
import novapi
import time
from mbuild.ranging_sensor import ranging_sensor_class
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.encoder_motor import encoder_motor_class

# 初始化
__ranger = ranging_sensor_class("PORT1", "INDEX1")
__rgb = dual_rgb_sensor_class("PORT2", "INDEX1")
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# 配置
__rgb.set_motor_diff_speed_kp(0.5)
OBSTACLE_THRESHOLD = 15  # 障碍物距离阈值

while True:
    # 同时读取多个传感器
    distance = __ranger.get_distance()
    diff = __rgb.get_motor_diff_speed()
    pitch = novapi.get_pitch()

    # 优先级 1：紧急避障
    if distance < OBSTACLE_THRESHOLD:
        __motor_L.set_power(0)
        __motor_R.set_power(0)
        print("⚠️ 前方障碍物！停止")
    else:
        # 优先级 2：巡线行进
        __motor_L.set_power(50 + diff)
        __motor_R.set_power(50 - diff)

    time.sleep(0.01)
```
