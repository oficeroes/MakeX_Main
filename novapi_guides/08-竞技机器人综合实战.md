## 2. 系统架构设计

### 程序状态机

```
        ┌─────────┐
        │  上电    │
        └────┬────┘
             │
        ┌────▼────┐     自动赛
        │ 检测模式 │─────────────────┐
        └────┬────┘                 │
             │ 手动赛               │
        ┌────▼────┐          ┌─────▼──────┐
        │ 遥控模式 │          │ 自动赛模式  │
        └────┬────┘          └─────┬──────┘
             │                     │
    ┌────────┼────────┐    ┌──────┼──────┐
    ▼        ▼        ▼    ▼      ▼      ▼
  底盘    武器控制  传感器  巡线   避障   策略
  遥控    按键触发   监控   行进   停止   执行
```

### 优先级体系

```
高优先级（安全相关）
  ├── 紧急避障（距离 < 10cm → 立即停止）
  └── 模式切换检测

中优先级（任务相关）
  ├── 巡线偏离修正
  └── 武器指令响应

低优先级（辅助功能）
  ├── 传感器数据记录
  └── 状态指示灯
```

## 3. 完整代码实现

```python
"""
竞技机器人完整程序
支持自动赛（巡线+避障）和手动赛（遥控+武器）
"""
import novapi
import time
from mbuild.encoder_motor import encoder_motor_class
from mbuild.smartservo import smartservo_class
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.ranging_sensor import ranging_sensor_class
from mbuild import gamepad
from mbuild import power_manage_module

# ==================== 配置常量 ====================
LOOP_DELAY = 0.01

# 底盘参数
BASE_SPEED = 50
TURN_SPEED = 40
DEAD_ZONE = 10

# 巡线参数
LINE_KP = 0.5

# 避障参数
OBSTACLE_STOP = 15       # 紧急停止距离（cm）
OBSTACLE_SLOW = 30       # 减速距离（cm）

# 武器参数
WEAPON_POWER = 100
WEAPON_REVERSE = -100

# ==================== 硬件初始化 ====================
# 底盘
__motor_L = encoder_motor_class("M1", "INDEX1")
__motor_R = encoder_motor_class("M2", "INDEX1")

# 武器
__weapon = smartservo_class("M3", "INDEX1")

# 传感器
__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
__ranger = ranging_sensor_class("PORT2", "INDEX1")

# 巡线配置
__rgb.set_motor_diff_speed_kp(LINE_KP)

# ==================== 辅助函数 ====================

def chassis_arcade(forward, turn):
    """
    街机式底盘控制
    forward: 前进动力 (-100~100)
    turn:    转向动力 (-100~100)
    """
    L = forward + turn
    R = forward - turn
    L = max(-100, min(100, L))
    R = max(-100, min(100, R))
    __motor_L.set_power(L)
    __motor_R.set_power(R)

def chassis_stop():
    """紧急停止"""
    __motor_L.set_power(0)
    __motor_R.set_power(0)

def weapon_control(power):
    """武器控制"""
    __weapon.set_power(power)

def check_obstacle():
    """
    检测障碍物
    返回: "danger" | "slow" | "clear"
    """
    d = __ranger.get_distance()
    if d < OBSTACLE_STOP:
        return "danger"
    elif d < OBSTACLE_SLOW:
        return "slow"
    return "clear"

# ==================== 手动赛模式 ====================

def manual_mode():
    """手动遥控模式"""
    # 读取摇杆
    Ly = gamepad.get_joystick("Ly")
    Rx = gamepad.get_joystick("Rx")

    # 死区
    if abs(Ly) < DEAD_ZONE:
        Ly = 0
    if abs(Rx) < DEAD_ZONE:
        Rx = 0

    # 底盘控制
    chassis_arcade(Ly, Rx)

    # 武器控制
    if gamepad.is_key_pressed("R1"):
        weapon_control(WEAPON_POWER)       # 武器正转
    elif gamepad.is_key_pressed("R2"):
        weapon_control(WEAPON_REVERSE)     # 武器反转
    elif gamepad.is_key_pressed("L1"):
        weapon_control(0)                  # 急停武器
    # 不按键时保持武器当前状态

    # 特殊功能键
    if gamepad.is_key_pressed("N1"):
        # 预设动作：快速前进 1 秒
        chassis_arcade(100, 0)
        time.sleep(1)
        chassis_stop()

# ==================== 自动赛模式 ====================

def auto_mode():
    """自动赛模式：巡线 + 避障"""
    # 传感器读取
    obstacle = check_obstacle()
    diff = __rgb.get_motor_diff_speed()

    if obstacle == "danger":
        # 紧急避障：立即停止
        print("⚠️ 紧急避障！")
        chassis_stop()

    elif obstacle == "slow":
        # 减速通过
        speed = BASE_SPEED * 0.4
        chassis_arcade(speed, diff)
        print("🐢 减速中... 距离:%.1f cm" % __ranger.get_distance())

    else:
        # 正常巡线
        chassis_arcade(BASE_SPEED, diff)

# ==================== 启动 ====================

print("=" * 40)
print("  竞技机器人启动")
print("=" * 40)

novapi.reset_timer()

# 判断比赛模式
AUTO = power_manage_module.is_auto_mode()

if AUTO:
    print("当前模式: 自动赛 🤖")
else:
    print("当前模式: 手动赛 🎮")
print("系统就绪！")

# ==================== 主循环 ====================

while True:
    # 持续检测模式切换
    current_mode = power_manage_module.is_auto_mode()

    if current_mode:
        auto_mode()
    else:
        manual_mode()

    time.sleep(LOOP_DELAY)
```

### 4.3 传感器联调测试

```python
"""传感器联调测试"""
import novapi
import time
from mbuild.dual_rgb_sensor import dual_rgb_sensor_class
from mbuild.ranging_sensor import ranging_sensor_class

__rgb = dual_rgb_sensor_class("PORT1", "INDEX1")
__ranger = ranging_sensor_class("PORT2", "INDEX1")

while True:
    d = __ranger.get_distance()
    s = "00" if __rgb.is_state("00") else \
        "01" if __rgb.is_state("01") else \
        "10" if __rgb.is_state("10") else "11"
```

## 5. 实战调试步骤

### 第 1 步：纯底盘遥控测试

只接电机，用手柄遥控确认能正常前进/后退/转向。

### 第 2 步：加入武器

接上舵机，测试肩键控制武器正反转。

### 第 3 步：加入传感器

接上 RGB 和激光测距，在串口确认数据正常。

### 第 4 步：自动赛巡线测试

在简单直道上测试巡线，逐步增加弯道难度。

### 第 5 步：自动赛避障测试

在巡线路线上放置障碍物，确认机器人能自动停止。

### 第 6 步：实战模拟

完整运行程序，在模拟比赛场景中测试自动赛和手动赛的切换。

## 6. 常见故障排查

| 症状           | 排查步骤                                                              |
| -------------- | --------------------------------------------------------------------- |
| 电机不转       | 1. 检查电池电量 2. 确认 M 端口连接正确 3. 换端口测试                  |
| 武器不受控     | 1. 确认智能舵机接在 M 端口 2. 检查 INDEX 是否正确                     |
| 巡线不识别     | 1. 检查轨道颜色是否为深黑色 2. 降低环境光照 3. 调整 `set_led_color()` |
| 手柄无响应     | 1. 确认手柄已配对 2. 检查 mBlock 中设备是否连接                       |
| 自动赛模式误判 | 1. 检查电源管理模块连接 2. 确认比赛系统开关正确                       |
