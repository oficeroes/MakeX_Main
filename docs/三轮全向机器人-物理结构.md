## 1. 整体拓扑

```
                    一号升降臂 (M4 + M6-1)
                    ╱
           M1 ←────●────→ M2
          ╱         ↑         ╲
         ╱         Face0       ╲
        ╱        (收球面)       ╲
       ╱       DC1 + BL1/BL2    ╲
      ╱          (发射小球)      ╲
     ╱                            ╲
    ╱     Face2              Face1 ╲
   ╱    (一号臂面)          (二号臂面)╲
  ╱                                  ╲
 M3 ←────────────────────────────────→ M2
                    二号升降臂 (M5 + M6-2)
```

**三个面（三角形三条边）**：

| 面编号 | 构成边    | 功能                  | 搭载设备                                               |
| :----: | --------- | --------------------- | ------------------------------------------------------ |
| Face 0 | **M1—M2** | 🎾 收球面（默认正面） | DC1 直流电机 → 收球履带<br>BL1+BL2 无刷电机 → 发射小球 |
| Face 1 | **M2—M3** | 🦾 二号升降臂面       | M5 编码电机（升降） + M6-INDEX2 舵机（夹取）           |
| Face 2 | **M3—M1** | 🦾 一号升降臂面       | M4 编码电机（升降） + M6-INDEX1 舵机（夹取）           |

> **关键认知**：切换正面不只是软件概念——不同面搭载不同硬件，面向不同任务。

## 2. 全向轮底盘（3 个编码电机）

```
        前进方向 (+Vy)
             ↑
      M1 ←──┼──→ M2      M1: 前左轮 @150°位置
             │            M2: 前右轮 @30°位置
             M3           M3: 尾部轮 @270°位置
```

|  编号  | 端口链 | 位置        | 用途       |
| :----: | ------ | ----------- | ---------- |
| **M1** | INDEX1 | 前左 (150°) | 全向驱动轮 |
| **M2** | INDEX1 | 前右 (30°)  | 全向驱动轮 |
| **M3** | INDEX1 | 尾部 (270°) | 全向驱动轮 |

三轮 120° 对称全向布局，支持前进后退、左右横移、原地自旋、斜向移动。

## 3. 三个功能面详解

### 3.1 Face 0（M1—M2）— 收球面 🎾

```
        M1 ●─────────● M2
        DC1(收球履带) → 管道 → BL1/BL2(发射)
```

| 设备        | 类型     | 控制方式   | 说明                                                          |
| ----------- | -------- | ---------- | ------------------------------------------------------------- |
| **DC1**     | 直流电机 | 动力扩展板 | +100 正转履带收球 → 推入管道，−100 反转吐球，0 停止           |
| **BL1/BL2** | 无刷电机 | 动力扩展板 | 位于管道上方，高速旋转将小球发射出去。R1 开关 / D-pad ←→ 调速 |

**操作**：N1 键切换 DC1 收球；R1 键切换 BL1+BL2 发射；D-pad ←→ 调节发射速度。

---

### 3.2 Face 1（M2—M3）— 二号升降臂 🦾

```
        M2 ●─────────● M3

          M5 (升降) + M6-2 (夹)
```

| 设备          | 类型     | 端口链         | 说明                                  |
| ------------- | -------- | -------------- | ------------------------------------- |
| **M5**        | 编码电机 | INDEX1         | 驱动机器爪**上升/下降**（有编码反馈） |
| **M6-INDEX2** | 智能舵机 | M6 端口 INDEX2 | 驱动机器爪**夹取/松开**               |

## 4. 全部硬件清单

### 4.1 编码电机（5 个）

| 编号 | INDEX  | 用途           | 需要闭环控制 |
| :--: | ------ | -------------- | :----------: |
|  M1  | INDEX1 | 前左全向驱动轮 | ✅ 底盘运动  |
|  M2  | INDEX1 | 前右全向驱动轮 | ✅ 底盘运动  |
|  M3  | INDEX1 | 尾部全向驱动轮 | ✅ 底盘运动  |
|  M4  | INDEX1 | 一号臂升降     | ✅ 升降定位  |
|  M5  | INDEX1 | 二号臂升降     | ✅ 升降定位  |

### 4.2 直流电机（1 个）— 收球

| 编号 | 通道       | 用途                        |
| :--: | ---------- | --------------------------- |
| DC1  | 动力扩展板 | 收球履带 → 将球推入发射管道 |

> DC1 是唯一的收球设备，N1 键切换开/关。

### 4.3 无刷电机（2 个）— 发射

| 编号 | 通道       | 用途           | 控制方式         |
| :--: | ---------- | -------------- | ---------------- |
| BL1  | 动力扩展板 | 发射小球（左） | set_power(0~100) |
| BL2  | 动力扩展板 | 发射小球（右） | set_power(0~100) |

> **球路流程**：DC1 收球 → 推入管道 → 管道上方 BL1/BL2 高速旋转将球发射出去。
> R1 键同时开关两个无刷电机，D-pad ←→ 调节转速（10~100）。
> 调试模式 ←/→ 可切换 BL1 → BL2 → BL12（双电机同时），
> BL12 模式下 N1 同时驱动 BL1+BL2 + DC1 以 -100 反转辅助供球。

### 4.4 舵机（1 个物理舵机，2 路）

| 端口 | INDEX  | 用途       | 方向约定 | 机械极限  |
| ---- | :----: | ---------- | -------- | :-------: |
| M6   | INDEX1 | 一号臂夹取 | 负=夹紧  | **≤300°** |
| M6   | INDEX2 | 二号臂夹取 | 负=夹紧  | **≤300°** |

> 🚨 **铁律**：0°=全开零点，负角度=夹紧，正角度会撑爆夹爪。夹紧幅度严禁超过 300°，否则齿轮扫齿/结构报废。自适应夹爪（R2）用速度堵转检测 + 角度硬限位双重保护。

### 4.5 显示屏

| 端口  | INDEX  | 类型                        |
| ----- | :----: | --------------------------- |
| PORT2 | INDEX1 | 8×16 LED 点阵屏（横屏模式） |

## 5. 面与任务对应

| 当前正面 | 对着对手的是 | 搭载设备                       | 功能键（规划中）       |
| :------: | ------------ | ------------------------------ | ---------------------- |
|  Face 0  | 收球履带     | 🎾 DC1 收球 + BL1/BL2 发射小球 | 键A=收球 键B=发射      |
|  Face 1  | 二号升降臂   | 🦾 M5 升降 + M6-2 夹取         | 键A=升降档位 键B=夹/放 |
|  Face 2  | 一号升降臂   | 🦾 M4 升降 + M6-1 夹取         | 键A=升降档位 键B=夹/放 |

> **设计理念**：L1 切换正面后，功能键自动重映射为当前面设备所需的操作。
> 例如：Face 0 下功能键控制收球/发射；切到 Face 1 后同样的按键变为升降/夹取。
> 具体按键分配尚未确定（待定）。

> **比赛策略**：按 L1 切换正面 → 车身旋转 120° → 不同设备对准目标 → 功能键自动适配 → 执行对应操作。
