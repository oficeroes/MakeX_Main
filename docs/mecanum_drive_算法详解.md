> **来源文件**：`mecanum_drive.py`（四轮麦克纳姆）、`mecanum_forward.py`（三轮全向）
> **运行环境**：MicroPython (Novapi)
> **更新日期**：2026-07-08

## 一、设计动机

### 旧算法的问题

旧算法有 7 层信号处理链，其中 3 层互相打架：

```
CURVE_LIFT=20 → 最小输出 20%
  + STARTUP_BURST +30% → 起步跳变到 50%
  → 150ms 后 BURST 结束 → 骤降到 17%
  → 低于电机堵转阈值 → 电机停转
```

**结果**：轻推摇杆 → 猛冲一下 → 自己停。更糟糕的是还有一个 500ms 才能启动的精细操控模式来"补救"，治标不治本。

### 新算法的思路

**核心原则**：稳态输出必须始终 ≥ 电机堵转阈值（实测约 15%），且不能有跳变。

```
低段线性（0~25% 摇杆 → 0~18% 功率）
  → 无 BURST、无 MIN_POWER、无 FINE_MODE
  → 电机从 0% 平稳起步，持续低速转动
  → 摇杆推大 → 高段指数平滑过渡到 100%
```

整个处理链从 7 层压缩到 **4 层**，移除全部冗余补偿，只剩必要环节。

## 四、两段式响应曲线（核心）

### 数学公式

$$
y = \begin{cases}
\displaystyle \frac{P_{out}}{P_{in}} \cdot x & 0 \leq x \leq P_{in} \\[8pt]
\displaystyle P_{out} + (100 - P_{out}) \cdot \left(\frac{x - P_{in}}{100 - P_{in}}\right)^E & P_{in} < x \leq 100
\end{cases}
$$

其中：

- $x$：摇杆绝对值（0~100）
- $P_{in}$：线性段拐点（`STICK_LOW_PIVOT = 25`）
- $P_{out}$：拐点输出（`STICK_LOW_OUT = 18`）
- $E$：高段指数（`STICK_HIGH_EXPO = 1.7`）

### 输出对照表

| 摇杆推幅 | 曲线输出 | × SPEED_SCALE(0.85) |       效果       |
| :------: | :------: | :-----------------: | :--------------: |
|    5%    |   18%    |        15.3%        |  最低速持续转动  |
|   10%    |   18%    |        15.3%        | 同上（线性段内） |
|   25%    |   18%    |        15.3%        |       拐点       |
|   30%    |   ~19%   |        ~16%         |      过渡区      |
|   50%    |   ~42%   |        ~36%         |       中速       |
|   75%    |   ~71%   |        ~60%         |       较快       |
|   100%   |   100%   |         85%         |       满速       |

### 设计要点

1. **低段线性（0~25% 摇杆）**：斜率 0.72，输入 5% → 输出 18%。确保任何非零输入都有足够功率克服静摩擦，且是**稳态**（不是临时爆发），电机持续转动。

2. **高段指数（25~100% 摇杆）**：从 18% 平滑过渡到 100%，曲线指数 1.7（介于线性和二次之间），兼顾低段细腻和高段爆发。

3. **DEAD_ZONE = 3**：仅过滤摇杆中位 ±3% 的电气噪声，不影响手感。

4. **平移和旋转共用同一曲线**：不再区分 JOYSTICK_EXPO 和 OMEGA_EXPO。旋转的低段表现与平移一致，轻推右摇杆即获得稳定低速旋转。

### 参数调优

| 参数              | 默认值 |  范围   | 调大→      |
| ----------------- | :----: | :-----: | ---------- |
| `STICK_LOW_OUT`   |   18   |  12~25  | 最低速更快 |
| `STICK_LOW_PIVOT` |   25   |  15~40  | 线性段更长 |
| `STICK_HIGH_EXPO` |  1.7   | 1.2~2.5 | 高段更"窜" |

如果你的电机堵转阈值不同（前述实测约 15%），优先调整 `STICK_LOW_OUT`。

## 五、运动学

### 四轮麦克纳姆（mecanum_drive.py）

```
M1 =  Vx + Vy + ω
M2 = -Vx + Vy - ω    → 取反（反向接线补偿）
M3 = -Vx + Vy + ω
M4 =  Vx + Vy - ω    → 取反（反向接线补偿）
```

内嵌三项重量补偿：

- `FRONT_BACK_COMPENSATION`：前轮加力、后轮减力
- `ROTATION_BALANCE`：旋转时前后均衡
- `STRAFE_VY_COUPLING`：平移防漂移

### 三轮全向（mecanum_forward.py）

```
M1 = -0.5·Vx - 0.866·Vy - ω
M2 = -0.5·Vx + 0.866·Vy - ω
M3 =  1.0·Vx            - ω
```

支持正面切换（L1 键旋转 120°）：

- `rotate_velocity(Vx, Vy, face)`：将摇杆向量旋转到当前正面坐标系
- 三个面：Face 0(默认), Face 1(+120°), Face 2(-120°)

### 公共

功率钳位：任一电机 |power| > 100 时等比缩放至 100%，保证方向不变。

## 八、移除项清单（旧算法 → 新算法）

| 移除项                                  | 原因                 | 行数 |
| --------------------------------------- | -------------------- | :--: |
| `CURVE_LIFT`                            | 被两段曲线替代       |  ~5  |
| `MIN_MOTOR_POWER` + `apply_min_power()` | 新曲线已保证最低输出 | ~16  |
| `STARTUP_BURST` 全套（常量+函数+调用）  | 与稳态低段不兼容     | ~25  |
| `FINE_CONTROL` 全套（常量+函数+调用）   | 新曲线低段天然精细   | ~55  |
| `JOYSTICK_EXPO` / `OMEGA_EXPO`          | 统一用新曲线参数     |  ~3  |
| `SLEW_RATE` 全套（仅 forward）          | 新曲线已平滑         | ~25  |
| `_burst_until` / `_last_nonzero`        | BURST 移除           |  ~2  |
| `_fine_*`（5 个全局变量）               | FINE 移除            |  ~5  |
| `_slew_last_power`（仅 forward）        | SLEW 移除            |  ~1  |
| `_raw_Lx/Ly/Rx`                         | 仅 FINE 使用         |  ~3  |

**总计减少约 140 行代码**，算法更简单、更稳定、更可预测。
