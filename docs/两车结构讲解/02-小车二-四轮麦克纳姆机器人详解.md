## 1. 硬件總覽（這輛車身上有什麼）

| 類別     | 數量 | 具體硬件                                               |
| -------- | :--: | ------------------------------------------------------ |
| 驅動電機 |  4   | M1 / M2 / M3 / M4 —— **編碼電機** + **麥克納姆輪**     |

| 執行舵機 |  2   | M6 端口鏈 **智能舵機** SV1（INDEX1）、SV2（INDEX2）    |

## 3. 底盤：硬件與運動學的搭配

### 3.2 逆運動學 + 反接補償（硬件接反，軟件兜底）

```python
def mecanum_kinematics(Vx, Vy, omega):
    M1 =  Vx + Vy + omega
    M2 = -Vx + Vy - omega
    M3 = -Vx + Vy + omega
    M4 =  Vx + Vy - omega
    M2 = -M2          # ← M2/FR 電機物理反接，軟件取反
    M4 = -M4          # ← M4/BR 電機物理反接，軟件取反
```

- **硬件事實**：M2 和 M4 兩臺電機是反向接線（省事/走線），
  軟件在運動學裏直接取反，讓"正功率=前進"的世界觀統一。
- 內嵌三組重量/裝配補償（軟開關，默認部分開啓）：
  - `FRONT_BACK_COMPENSATION`：前後輪出力不均補償（當前 0.0）
  - `ROTATION_BALANCE`：旋轉時前後均衡（當前 0.0）
  - `STRAFE_VY_COUPLING`：純橫移時會向前漂，按 |Vx| 減一點 Vy（當前 0.02）
- 任一電機超 ±100 → 四輪等比縮放，方向不變。

### 3.3 方向校準（接線錯了不用改線，改常量）

| 常量           | 當前值 | 作用                                       |
| -------------- | :----: | ------------------------------------------ |
| `INVERT_VX`    | False  | 左右反了 → True                            |
| `INVERT_VY`    |  True  | 前後反了 → True（當前已反）                |
| `INVERT_OMEGA` |  True  | 旋轉方向反了 → 取反                        |
| `face_flipped` | False  | L1 鍵運行時把前後左右整體取反（正開/倒開） |

> 遙控信號鏈（與小車一相同的兩段式響應曲線，本車拐點用 20）：
> `死區(3) → 響應曲線(低段線性/高段指數) → ×SPEED_SCALE(0.65) → INVERT_* → face_flipped → 運動學 → set_power`

## 4. 功能系統逐個拆解（硬件 ↔ 軟件怎麼搭配）

### 4.1 收球 —— DC1 / DC2（直流履帶）+ 滾球 M5

代碼把這幾個設備綁成兩組"聯動動作"，按一個鍵同時驅動多個電機：

| 按鍵 | 軟件動作                           | 硬件效果（按當前代碼設定）             |
| :--: | ---------------------------------- | -------------------------------------- |
|  N2  | `M5=-80` + `DC1=-100` + `DC2=-100` | 雙履帶收球 + 滾球電機反轉向內送        |
|  N4  | `M5=+80` + `DC2=+100`              | 滾球電機正向 + DC2 正向（出/送球方向） |

- N2 / N4 互斥：開 N2 會自動關 N4，反之亦然
- `DC_COLLECTOR_SPEED = 100`（基礎轉速常量，實際按上面組合值使用）
- 自動程序裏也能逐臺驅動：`('dc_motor','DC1',-86)`、`('motor','M5',-66)` 等

> 具體每臺電機正負號代表"收"還是"吐"，取決於機械裝配方向 ——
> 代碼只是當前標定值，**換機構後必須在場上實測確認方向**。

### 4.2 發射 —— BL1 / BL2（無刷電機）+ 聯動舵機 SV1 / SV2

|  按鍵   | 軟件動作                                         | 說明              |
| :-----: | ------------------------------------------------ | ----------------- |
|   L2    | 切換 BL1 開/關（與 BL2 互斥）                    | 開 BL1 自動關 BL2 |
|   R2    | 切換 BL2 開/關（與 BL1 互斥）                    | 開 BL2 自動關 BL1 |
| D-pad ↑ | 發射速度在預設 `[45,50,60]` 循環上調             | `BL_ACTION_SPEED` |
| D-pad ↓ | 預設循環下調                                     |                   |
|   N1    | **觸發與"正在轉的那個無刷"配對的舵機做一次擊發** | 見下方交叉映射    |

**舵機與無刷是交叉配對的**（代碼裏的實際邏輯）：

| 當前狀態           | N1 觸發哪個舵機 | 動作                               |
| ------------------ | :-------------: | ---------------------------------- |
| BL1 在轉（BL2 停） |       SV2       | `move_to(SERVO2_ACTION_ANGLE=38)`  |
| BL2 在轉（BL1 停） |       SV1       | `move_to(SERVO1_ACTION_ANGLE=-38)` |
| 兩個都沒轉         |    （拒絕）     | LED 顯示 `LOCK`，舵機被鎖住不動作  |

- 動作角度 `SERVO1_ACTION_ANGLE=-38` / `SERVO2_ACTION_ANGLE=38`（方向相反的兩側機構）
- 舵機以 `SERVO_ACTION_SPEED=50` 擺到角度後，延時 `SERVO_RETURN_DELAY=0.18s` **自動回中 0°**
- 用途是配合無刷"推/撥"一下球，形成發射動作；**無刷沒開時按 N1 無效（防誤擊發）**

### 4.3 第三路直流 DC3 —— 振盪

| 按鍵    | 軟件動作                                             |
| ------- | ---------------------------------------------------- |
| D-pad ← | DC3 振盪開關：開 = 每 0.5s 在 +100 / -100 間翻轉一次 |

- 用途：讓第三路直流小幅度往復擺動（防卡球/疏導等），具體看裝配
- 再按一次 D-pad← 停止

### 4.4 L1 —— "車頭翻轉"（純軟件，不動硬件）

- 前後左右完全對稱的車沒有"面"，但操作者繞到另一側時方向會反
- L1 切換 `face_flipped`：把 `Vx`、`Vy` 整體取反 = 正開 ↔ 倒開
- 純軟件映射，車身不轉、電機不倒轉方向之外的事

### 4.5 LED 屏 —— 狀態心跳

- 接 **PORT3·INDEX1**（與小車一的 PORT2 不同！兩車各佔一個口）
- 常顯 `Sxx`（當前發射速度）；特殊狀態：`LOCK`（無刷沒開按 N1）、`Main`、調試時的電機名 `M1`…`BL2`、`SV1` 等

## 5. 軟件總體架構（這些硬件是怎麼被"編排"起來的）

### 5.1 一個主循環，三種模式

```
while True:
  ① 自動程序（auto_mode，+ 鍵進入）      ← 最高優先
  ② 調試模式（debug_mode，≡ 鍵進入）      ← 逐電機/舵機/無刷測試
  ③ 正常遙控模式（默認）
```

- 主循環 `LOOP_DELAY = 0.02s`（50Hz）
- 按鍵一律**邊沿觸發**（`cur_X and not last_X`）
- **D-pad 衝突保護**：同時按 ←+→ 或 ↑+↓ 連續 3 幀 → 判定爲誤觸並屏蔽
- 本文件**保留了大量 `print(">>> …")`** —— 連 USB 調試時能看到日誌（小車一把 print 屏蔽了，本車沒有，兩車取捨不同）

### 5.2 遙控信號鏈（與小車一共用同一套算法）

```
死區過濾(±3) → 兩段響應曲線(拐點20 → 輸出18%，高段指數1.7) → ×SPEED_SCALE(0.65)
→ INVERT_VX/VY/OMEGA 方向校準 → face_flipped 翻轉 → mecanum_kinematics() → 四輪 set_power()
```

- 左搖桿全向（含橫移、斜行），右搖桿原地自旋
- 曲線低段線性保證**輕推即有 ≥18% 穩態輸出**（高於電機堵轉閾值 ~15%），杜絕"起步猛衝又停"

### 5.3 自動程序：兩種"劇本格式"

按 `+` 進入，先 `_reset_drive_encoder_reference()` 把四輪編碼器清零，再逐條執行。

**格式 A：連續軌跡步（老格式）**

```python
(持續秒, Vx, Vy, omega)
```

- 每步之間 `AUTO_RAMP_MS=40ms` 線性插值（防速度跳變打滑）
- 可選 `AUTO_ACCEL_MS` 步內梯形加速（當前 0 = 關）

**格式 B：指令步（新格式，字符串標籤開頭）**

| 標籤                   | 含義                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| `enc_move`             | 編碼器閉環直/斜行（按功率比例把目標角度分給 4 輪，`move()` 到點） |
| `enc_rot`              | 編碼器閉環原地自旋                                                |
| `enc_moverot`          | **邊走邊轉**：平移+旋轉目標疊加，一次性 `move()` 到位             |
| `open_move`            | 開環走 + 用四輪編碼和實時糾偏航向（`OPEN_HEADING_*`）             |
| `motor`                | 任意編碼電機 M1~M5 開指定功率                                     |
| `dc_motor`             | 任意直流 DC1~DC3 開指定功率（記入 `_dc_hold` 保持）               |
| `servo`                | 舵機 `move_to(角度, 速度)`，等待 `wait_ms`                        |
| `delay`                | 純延時                                                            |
| `spin`                 | 時間驅動自旋（非編碼器，轉得快）                                  |
| `enc_stop`             | 停所有電機 + 清 DC 功率（`_stop_dc_all()`）                       |
| `traj_v` / `traj_stop` | GUI 連續軌跡專用步                                                |

- 編碼器標定換算：`ENCODER_TICKS_PER_CM=70.287`、`TURN_TICKS_PER_DEG=11.1435`
- `_resolve_zero_enc_move()`：如果某步速度向量是 0（畫軌跡留下的），自動用相鄰步向量"補腦"
- 特殊能力：**連續 enc_move 步之間不剎停**（`stop_motors=False`），走位更順

### 5.4 調試模式（≡）—— 四個硬件類別逐個測

| 類別     | 對象                   | 測試鍵                                                                             |
| -------- | ---------------------- | ---------------------------------------------------------------------------------- |
| 編碼電機 | M1 / M2 / M3 / M4 / M5 | N1 正轉 / N4 反轉 / N2·N3 調速度(±10)                                              |
| 直流電機 | DC1 / DC2              | 同上                                                                               |
| 無刷電機 | BL1 / BL2              | N1 轉 / N4 停                                                                      |
| 舵機     | SV1 / SV2              | N1 轉到當前角度 / N4 回 0 / N2·N3 調角度(±2) / R1 設零點 / R2 存動作角 / L1 翻方向 |

- 切換：↑/↓ 換類別，←/→ 換對象，LED 顯示對象名
- 可用來**現場標定**舵機動作角（R2 會把當前角度寫回 `SERVO1/2_ACTION_ANGLE` 內存值）
- 調試裏也能直接按 `+` 啓動自動程序

## 7. 軟件搭配上的注意點

1. **兩車共用同一套遙控算法**（兩段式響應曲線 + 死區 + 方向校準），
   但參數不同：本車 `SPEED_SCALE=0.65`、拐點 20、三向都做了反轉校準；小車一 0.85、拐點 25。
2. **本車沒有 try/except 全禁的約束那麼敏感的歷史包袱**，但同樣建議少新增異常處理；
   關鍵差異是它**保留了 print 日誌**（USB 調試友好），小車一則因內存/字節碼把 print 換成空函數。
3. **舵機是"動作型"不是"保持型"**：擺到角度後 0.18s 自動回中 —— 改角度前想清楚它是往復動作。
4. **無刷互斥**：BL1/BL2 同一時刻只允許一個在轉（防電流過大/結構干涉）。
5. **自動程序結束會清 DC 功率**（`enc_stop` → `_stop_dc_all`），但 `stop_all_motors()` 不清 DC ——
   這是刻意設計：手動按 N2/N4 開着的收球狀態在自動結束後不會自己亂關/亂開。

---

> **總結一句話**：小車二 = X 型麥克納姆四輪底盤（全向/斜行穩、負載大）
> ＋ M5 滾球電機 ＋ DC1/DC2 收球履帶（DC3 振盪輔助）＋ BL1/BL2 雙無刷發射 ＋ 聯動舵機擊發。
> 軟件的核心工作：**用運動學+反接補償把"接反的輪子"統一成直覺操控；用聯動按鍵把"收-滾-射"流水線一鍵化；用編碼器閉環把自動走位做準。**
