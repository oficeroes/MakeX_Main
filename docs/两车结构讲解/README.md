## 两台车一句话对比

| 维度     | 小车一 · 三轮全向                                 | 小车二 · 四轮麦克纳姆                       |
| -------- | ------------------------------------------------- | ------------------------------------------- |
| 轮子     | 3 × 全向轮（编码电机）                            | 4 × 麦克纳姆轮（编码电机，2 个反接）        |
| 移动     | 全向 + **原地转 120° 换面**                       | 全向 + 斜行稳、负载能力更好                 |
| 特色结构 | 三角形三边各挂一套设备，**换面切换任务**          | 前后对称，**一条"收球→滚球→发射"流水线**    |
| 机械臂   | 两条升降臂（M4/M5，PID 位置闭环）+ 夹爪           | 滚球电机 M5，无升降臂                       |
| 球路     | DC1 收球 → BL1 发射（单通道球路）                 | DC1/DC2 收球 → M5 滚球 → BL1/BL2 + 舵机击发 |
| 舵机     | SV1/SV2 夹爪（限位/超时→保持，R2 松开）+ SV3 备用 | SV1/SV2 与无刷联动、往复击发后自动回中      |
| LED      | **PORT2**·INDEX1                                  | **PORT3**·INDEX1（注意不同口）              |
| 模式     | 阶段选择 / 换面 / 自动 / 遥控                     | 自动 / 调试 / 遥控                          |
| print    | 已替换为空函数（省内存）                          | 保留 `print(">>>")`（USB 调试用）           |

## 两台车的"软件搭配"共同底盘

无论哪台车，Novapi 代码都遵循同一套软件范式（细节见各车文章）：

1. **一个 `while True` 主循环**，50Hz（`0.02s`），靠 `time.sleep` 定拍。
2. **按键全部边沿触发**（`cur_X and not last_X`），避免按住重复执行；每帧末统一更新 `last_*`。
3. **LED 是唯一人机界面**（8×16 点阵屏，只支持 ASCII），`print()` 上传后不可见。
4. **同一套遥控手感算法**：
   死区过滤 → 两段式响应曲线（低段线性保证 ≥ 堵转阈值 / 高段指数爆发）→ 全局速度倍率 → 方向校准。
5. **编码器闭环**是自动走位/换面的精度来源（先标定 `ENCODER_TICKS_PER_CM` / `TURN_TICKS_PER_DEG`）。
6. **自动程序 = 一张剧本表**（`AUTO_SEQUENCE`），由 `trajectory_planner` GUI 生成或手写，`+` 键播放。
7. **Novapi 字节码上限很紧**（实测余量 ~150–200 B）：加功能要克制、逐个验证，`ast.parse` 通过 ≠ 能跑。

## 建议阅读顺序（做大总结用）

1. 先看两篇详解文章的 **"硬件总览" + "端口接线表"**，建立"这辆车上有什么"的清单。
2. 再看 **"功能系统逐个拆解"**，理解每个硬件在软件里对应哪个对象、哪组按键。
3. 最后看 **"软件总体架构"**，把硬件串成"模式 → 子系统 → 状态机"的整体。
4. 需要更深的算法/公式：`docs/遥控算法详解-可复用到任意底盘.md`、`docs/mecanum_drive_算法详解.md`、
   `docs/三轮全向机器人-代码详解.md`、`robot_kinematics_reference/`（运动学数学）。
