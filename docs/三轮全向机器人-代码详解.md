## 1. 系统架构

### 1.1 主循环结构

```
while True:
    ├── 自动模式 (auto_mode)
    │   ├── 特殊标签步 (encoder_cal / enc_move / enc_rot / enc_stop / spin / delay / motor / dc_motor / servo)
    │   └── 标准运动步 (4元组: 时间 + Vx + Vy + omega)
    │
    ├── 调试模式 (debug_mode)
    │   ├── 标定子模式 (debug_cal_mode)
    │   └── 主调试模式 (编码电机/直流/升降臂/舵机/无刷 逐项测试)
    │
    └── 正常模式 (手动遥控)
        ├── 面切换旋转中 → PID tick + 连按叠加
        ├── 摇杆读取 + 按键处理
        ├── 无刷电机 (R1 开关 + D-pad ←→ 调速)
        ├── 升降臂档位 (D-pad ↑↓ / N3砸底归零)
        ├── 自适应夹爪 (R2 切换 + 每帧速度/角度监测)
        ├── 升降臂 PID tick (每帧)
        ├── 死区 → 指数曲线 → 速度缩放 → 方向校准
        ├── 正面旋转 → 运动学解算 → 电机输出
        └── LED 显示
```

### 1.2 三种模式的优先级

| 优先级 | 模式     | 触发方式 | 说明                             |
| ------ | -------- | -------- | -------------------------------- |
| 最高   | 自动模式 | `+` 键   | 遥控完全禁用，程序结束后自动恢复 |
| 中     | 调试模式 | `≡` 键   | 逐电机测试，遥控禁用             |
| 正常   | 遥控模式 | 默认     | 全功能遥控 + 面切换              |

## 2. 数学基础

### 2.1 三轮全向运动学

```
          前进方向 (+Vy)
               ↑
        M1 ←──┼──→ M2      (前左 M1 @150°, 前右 M2 @30°)
               │
              M3            (尾部 M3 @270°)
```

**逆运动学方程**（输入速度 → 输出电机功率）：

```
M1_power = -0.5·Vx - 0.866·Vy - ω
M2_power = -0.5·Vx + 0.866·Vy - ω
M3_power =  1.0·Vx            - ω
```

其中：

- `Vx`：横向速度（+右, -左）
- `Vy`：纵向速度（+前, -后）
- `ω`：旋转速度（+顺时针, -逆时针）

**关键特性**：当任意电机功率超过 ±100 时，三路等比缩放，保持运动方向不变。

### 2.2 摇杆响应曲线（分段线性+指数）

采用 **分段曲线** 实现低速精准 + 高速爆发：

- **低速段** ($|x| \leq 25$)：线性映射 → 输出 $0 \sim 18\%$
- **高速段** ($|x| > 25$)：指数曲线 $t^{1.7}$ → 输出 $18\% \sim 100\%$

```
output = sign(x) × {
    18 × |x| / 25                    (|x| ≤ 25,  线性区)
    18 + 82 × ((|x|-25)/75)^1.7     (|x| > 25,  指数区)
}
```

| 摇杆推幅 | 输出 | 说明       |
| -------- | :--: | ---------- |
| 10%      | 7.2% | 线性区     |
| 25%      | 18%  | 线性区上限 |
| 50%      | ~38% | 指数区起步 |
| 75%      | ~70% | 快速拉升   |
| 100%     | 100% | 满功率     |

**相关常量**：`STICK_LOW_PIVOT=25`, `STICK_LOW_OUT=18`, `STICK_HIGH_EXPO=1.7`

### 2.3 正面旋转矩阵

三个正面本质上是将摇杆坐标系旋转 0° / +120° / -120°：

```
Face 0 (默认):  Vx' =  1.0·Vx + 0.0·Vy    Vy' =  0.0·Vx + 1.0·Vy   (不变)
Face 1 (右切):  Vx' = -0.5·Vx - 0.866·Vy  Vy' =  0.866·Vx - 0.5·Vy (+120°)
Face 2 (左切):  Vx' = -0.5·Vx + 0.866·Vy  Vy' = -0.866·Vx - 0.5·Vy (-120°)
```

预计算为 `FACE_ROTATIONS` 数组，循环中避免重复计算三角函数。

### 2.4 PID 控制器（面切换旋转）

```
omega = Kp·error + Ki·∫error·dt + Kd·d(error)/dt
```

| 参数          | 作用                       | 过大后果       |
| ------------- | -------------------------- | -------------- |
| **Kp** (比例) | 主力响应，误差越大输出越大 | 震荡           |
| **Ki** (积分) | 消除末尾静差               | 超调、积分饱和 |
| **Kd** (微分) | 抑制震荡，预测趋势         | 抖动、噪声放大 |

**积分限幅**：`|integral| ≤ MAX_SPEED / KI`，防止积分饱和（windup）。

### 2.5 余弦减速曲线

接近目标时（误差 < 目标的 DECEL_ZONE%），速度按余弦曲线平滑降速：

```
speed_limit = MIN_SPEED + (MAX_SPEED - MIN_SPEED) × cos(progress × π/2)
```

其中 `progress` 从 0（刚进入减速区）到 1（到达目标）。这条曲线在起点斜率为 0（无缝衔接），终点平滑降到最低速度。

## 3. 遥控操控

### 3.1 摇杆处理流水线

```
原始值 (-100~100)
  → apply_dead_zone()       死区过滤 (|x|<3→0)
  → apply_response_curve()  分段曲线 (线性+1.7次幂)
  → × SPEED_SCALE           全局缩放 (×0.85)
  → INVERT_*                方向校准
  → rotate_velocity()       正面旋转
  → × VY_BOOST              纵向增强 (×1.40)
  → omni_kinematics()       运动学解算
  → motor.set_power()       输出
```

> **VY_BOOST**：前进/后退方向额外增强 1.40×，补偿纵向摩擦力差异。调整此值可改变前进灵敏度。

> **print 抑制**：代码开头有 `print = _safe_print`（空函数），将所有 `print()` 静默。因为代码上传机器人后 `print()` 无任何输出——机器人唯一输出是 LED 点阵屏。

### 3.2 左摇杆 → 全向移动

| 操作 | Lx  | Ly  | 效果     |
| ---- | :-: | :-: | -------- |
| ↑    |  0  |  +  | 前进     |
| ↓    |  0  |  −  | 后退     |
| ←    |  −  |  0  | 左横移   |
| →    |  +  |  0  | 右横移   |
| ↖    |  −  |  +  | 左前斜向 |
| ↗    |  +  |  +  | 右前斜向 |

### 3.3 右摇杆 → 原地自旋

| 操作 | Rx  | 效果 |
| ---- | :-: | ---- |
| ←    |  −  | 左转 |
| →    |  +  | 右转 |

> **注意**：`INVERT_OMEGA = False` 表示右摇杆不做额外取反。如果右摇杆左右反转，将此常量改为 `True`。

### 3.4 死区 (Dead Zone)

摇杆在中位附近有微小抖动（±1~2 左右）。`DEAD_ZONE = 3` 将这些微小值归零，防止机器人静止时微微抖动。

## 4. 正面切换系统

### 4.1 设计动机

三轮全向机器人有三个"面"（三角形的三条边），默认 M1-M2 边为正面。
不同面搭载不同设备（收球/发射、升降臂/夹爪），比赛中需要切换正面以应对不同方向的任务。

### 4.2 工作原理

切换正面不是简单地改一个变量——摇杆坐标系需要**旋转 120°**，使"前进"方向始终对应新正面的法线方向。

```
Face 0 → Face 1: 坐标系旋转 +120°
Face 1 → Face 2: 坐标系旋转 +120°
Face 2 → Face 0: 坐标系旋转 +120°（回到起点）
```

### 4.3 ✅ 已实现：换面后功能键自动重映射

切换正面后，功能键的含义自动变化为当前面设备的操作：

| 当前面 | 搭载设备              | 功能键A       | 功能键B       |
| :----: | --------------------- | ------------- | ------------- |
| Face 0 | DC1 + BL1/BL2         | 收球（开/关） | 发射（开/关） |
| Face 1 | M4(升降) + M6-2(夹取) | 升降档位切换  | 夹取/松开     |
| Face 2 | M5(升降) + M6-1(夹取) | 升降档位切换  | 夹取/松开     |

> 具体按键尚未确定。当前代码仍使用固定按键映射。

### 4.4 面切换 + 车身旋转

按 L1 时：

1. `face = (face + 1) % 3` —— 逻辑切换
2. `face_rotate_start()` —— 启动 PID 闭环旋转 120°
3. 旋转期间遥控禁用，完成后恢复

### 4.5 连续换面

旋转中再次按 L1 → 叠加一个面（`face_rot_target_deg += FACE_ROTATE_WHEEL_DEG`），重置超时计时。快速按两下 = 一次性转 240°。

## 5. L1 编码器闭环换面

### 5.1 概述

这是整个程序中最复杂的子系统，实现了**编码器反馈 + PID 控制 + 余弦减速**的闭环旋转。

### 5.2 为什么不用时间开环？

时间开环的致命问题：

- 电池电压变化 → 电机转速变化 → 角度不准
- 地面摩擦力不同 → 同样时间转不同角度
- 每次误差累积 → 换几次面后方向完全偏了

编码器闭环**以实际转动的角度为准**，不受上述因素影响。

### 5.3 控制流程

```
face_rotate_start()
  ├── 记录三轮起始编码值
  ├── 设定目标 = FACE_ROTATE_WHEEL_DEG
  ├── 清零 PID 状态
  └── face_rotating = True

每循环 face_rotate_tick():
  ├── 读三轮当前编码 → 取平均增量
  ├── error = 目标 - 当前
  ├── 到位检测 → 稳定确认 → 完成
  ├── PID 计算 omega
  ├── 余弦减速（接近目标时）
  ├── 限幅 + 最小速度兜底
  ├── 方向取反（物理电机方向修正）
  └── omni_kinematics(0, 0, omega) → 输出
```

### 5.4 到位检测 + 稳定确认

不是简单的"误差 < 死区 → 完成"，而是两阶段：

1. **进入死区**：`|error| ≤ FACE_ROTATE_DEADBAND` → 开始计时
2. **稳定确认**：在死区内连续保持 `FACE_ROTATE_SETTLE_TIME` 秒 → 确认真完成

如果中途误差跳出死区 → 重置计时，重新追赶。这避免了"惯性冲过死区后立即判定完成"的误判。

### 5.5 关键常量校准

| 常量                    | 含义                     | 校准方法                       |
| ----------------------- | ------------------------ | ------------------------------ |
| `FACE_ROTATE_WHEEL_DEG` | 120°底盘旋转对应轮子角度 | 设置初值→测实际转角→按比例调整 |

**校准公式**：`新值 = 旧值 × (120° ÷ 实测转角)`

## 6. 自动程序系统

### 6.1 概述

自动程序通过 `AUTO_SEQUENCE` 列表定义，由 `trajectory_planner` GUI 工具生成。按 `+` 键触发，运行期间遥控禁用。

### 6.2 步骤类型

#### 标准运动步（4 元组）

```python
(持续时间_秒, Vx, Vy, omega)
```

- 支持方向和速度的步间线性插值（`AUTO_RAMP_MS`）
- 支持步内加速斜坡（`AUTO_ACCEL_MS`，0→100→0 梯形）
- 步间 Vx/Vy 会先经过 `rotate_velocity()` 做正面旋转

#### 编码器闭环步（enc_move）

```python
('enc_move', total_ticks, vy_power, vx_power)
```

- 使用 novapi 内置 `move()` 位置闭环，每个轮子独立跑到目标角度
- `total_ticks` = 厘米 × `ENCODER_TICKS_PER_CM`
- **算法**：运动学反解出各轮功率比 → 按比例分配角度增量 → 各轮同时 move() 到目标
- **连续衔接**：连续 enc_move 不刹停，直接衔接（`stop_motors=False`）

#### 编码器自旋步（enc_rot）

```python
('enc_rot', total_ticks, 0, omega_power)
```

- 同 enc_move，但用于原地自旋
- 也支持连续衔接

#### 组合闭环步（enc_moverot）

```python
('enc_moverot', total_ticks, vy_power, vx_power, omega_power, rot_ticks)
```

- **边走边转**：平移和旋转的目标角度叠加后一次性 move() 到位
- `total_ticks` = 平移距离，`rot_ticks` = 旋转量（刻度同 enc_move）
- 三轮同时到达各自组合目标，实现平移+旋转的协调运动

#### 位置闭环步（motor_pos）

```python
('motor_pos', motor_id, target_deg, kp, ki, kd)
```

- 通用编码电机位置 PID（M1~M5），跑到目标角度即停
- **即发即走**：启动后立即前进到下一步，PID 后台运行
- 可用于边走边升降（升降臂 PID 与底盘移动并行）
- 详见 [第 16 节](#16-通用编码电机位置-pid)

#### 停止缓冲（enc_stop）

```python
('enc_stop', 0, 0, 0)
```

- 短暂停顿，不终止整个序列
- 用于 enc_move 段之间的明确分隔

#### 时间自旋（spin）

```python
('spin', degrees, omega_power)
```

- 时间驱动（非编码器），适用于快速旋转
- `degrees` 为目标旋转角度，`omega_power` 为速度

#### 其他标签

| 标签          | 格式                               | 说明               |
| ------------- | ---------------------------------- | ------------------ |
| `delay`       | `('delay', 秒数)`                  | 纯延时等待         |
| `motor`       | `('motor', 'M1', 功率)`            | 持续转动某编码电机 |
| `dc_motor`    | `('dc_motor', 'DC1', 功率)`        | 持续转动某直流电机 |
| `encoder_cal` | `('encoder_cal', 时长, Vx, Vy, ω)` | GUI 编码器标定     |

### 6.3 步间插值 (AUTO_RAMP_MS)

进入新步骤的前 `AUTO_RAMP_MS` 毫秒内，速度从上一拍的终值**线性插值**到当前拍的目标值。避免速度跳变 → 电流冲击 / 轮子打滑。

```
alpha = elapsed_ms / AUTO_RAMP_MS          (0 → 1)
Vx_out = prev_Vx + (target_Vx - prev_Vx) × alpha
```

### 6.4 步内加速斜坡 (AUTO_ACCEL_MS)

每步内部的功率曲线：**0 → 100% → 0**，呈梯形。

```
         功率
          ↑
    100%  │     ████████
          │   ╱          ╲
      0%  │ ╱              ╲
          └──────────────────→ 时间
          加速段  匀速段  减速段
```

步长不足以容纳完整梯形时（`step_ms ≤ ACCEL_MS × 2`），不启用斜坡。

## 8. 无刷电机系统

### 8.1 概述

BL1/BL2 两个无刷电机位于收球管道上方，高速旋转将球发射出去。
球路：DC1 收球 → 推入管道 → BL1/BL2 发射。

### 8.2 正常模式操作

| D-pad ← | 发射速度 -5      |        —        |
| D-pad → | 发射速度 +5      |        —        |
| 按 N1   | DC1 收球开关     |        —        |

- 速度范围 10~100，启动默认 80
- 收球（DC1）与发射（BL）完全独立，不联动

### 8.3 调试模式操作

| ---- | ----------------------------------- |

| N4   | 停止                                |
| N2   | 测试速度 +10（上限 100）            |
| N3   | 测试速度 -10（下限 0）              |

- **BL12 模式**：N1 同时驱动 BL1 + BL2，并自动将 DC1 设为 -100 反转辅助供球；N4 全部停止

### 8.4 关键常量

| 常量              | 默认值 | 说明                 |
| ----------------- | :----: | -------------------- |
| `BL_ACTION_SPEED` |   80   | 无刷电机发射默认速度 |
| `BL_SPINUP_DELAY` |  0.1   | 启动延迟（秒）       |

### 8.5 安全说明

> 无刷电机转速极高，测试时确保发射口无人。调试模式 N1 按下即转，松开即停（N4 停）。

## 9. 升降臂系统

### 9.1 概述

机器人有两个升降臂：

- **一号臂**：M5 编码电机（升降）+ M6-INDEX1 舵机（夹取）— PID 控制 ✅
- **二号臂**：M4 编码电机（升降）+ M6-INDEX2 舵机（夹取）— PID 控制 ✅

> ⚠️ **方向差异**：M4（二号臂）正速=向上，M5（一号臂）正速=向下（反转安装）。
> 代码通过 `LIFT_DIR = [1, -1]` 自动补偿，PID 内部统一用"目标>当前=正功率"，输出时乘以方向系数。

升降臂到位后自动停电，依靠机械蜗杆自锁维持位置。

> ✅ 双升降臂 PID 均已实现，M4（二号臂）与 M5（一号臂）共用相同的 PID 参数和档位表。
> 换面后 D-pad ↑↓ 自动切换为当前面升降臂的档位控制。

### 9.2 正常模式操作

| 操作    | 功能               |      LED       |
| ------- | ------------------ | :------------: |
| D-pad ↑ | 升一档 L0→L1→L2→L0 | `L0` `L1` `L2` |
| D-pad ↓ | 降一档             | `L0` `L1` `L2` |
| D-pad ← | 微调 -15°          |       —        |
| D-pad → | 微调 +15°          |       —        |
| N3      | 砸底归零 L0        |      `L0`      |

> **微调说明**：D-pad ←→ 在档位基础上做 ±15° 精细增减。切换档位（↑↓/N2/N3）时微调偏移自动归零。
> **N3 归零**：驱动臂持续下压直到堵转（编码器停止变化 0.3s），记录该位置为新的零位。下次 PID 移动以此为零基准。
> **开机自动归零**：每次上电后，M4 和 M5 立即自动执行砸底归零，LED 显示 `HOME`，完成后进入主界面 `Main`。

### 9.3 预设档位

| 档位 | 角度 | 说明         |
| :--: | :--: | ------------ |
|  L0  |  0°  | 底部（零点） |
|  L1  | 330° | 第一档       |
|  L2  | 660° | 第二档       |

### 9.4 PID 控制流程

```
lift_pid_start(目标角度)
  → 每帧 lift_pid_tick():
      ├─ 读编码器角度 → 减去零偏移(_lift_zero_offset) → 计算误差
      ├─ 根据误差方向选择最小速度:
      │     error>0 (需上升) → LIFT_MIN_SPEED (40%)
      │     error<0 (需下降) → LIFT_MIN_SPEED_DOWN (45%)
      ├─ PID 计算功率 (Kp=0.7, Ki=0.08, Kd=0.02)
      ├─ 余弦减速（接近目标时丝滑降速，下限为方向对应的最小速度）
      ├─ 方向补偿: power *= LIFT_DIR[motor_idx]  (M5反转)
      ├─ 到位检测: 误差<6° → 稳定 0.3s → set_power(0) 停电
      └─ 超时 3s → 强制停电
```

> **关键设计**：下降方向使用更高的最小功率（45% vs 40%），突破皮带/蜗杆的静摩擦力，
> 避免微调下降时"推不动→累积→突然滑落"的问题。上升方向保持较低最小功率以减少过冲。
> 停电后机械蜗杆自锁维持位置，避免电机持续通电过热。
> `_lift_zero_offset` 记录砸底归零后的编码器偏移，每次 PID 都减掉，使零位始终对应物理底部。

### 9.5 微调功能

升降臂支持在预设档位基础上用 D-pad ←→ 做小幅度精细增减（默认 ±15°/次）：

- `lift_fine_offset = [0, 0]`：记录各臂的微调偏移量
- 实际目标角度 = `DEBUG_LIFT_GEARS[档位] + lift_fine_offset`
- 切换档位（↑↓/N2）或归零（N3）时，偏移自动归零
- 向左微调有下限保护（≥ 0°），防止负角度

**关键常量**：

| 常量             | 默认值 | 说明          |
| ---------------- | :----: | ------------- |
| `LIFT_FINE_STEP` |   15   | 每次微调角度° |

### 9.6 砸底归零（L0 档）

按 N3 触发 L0 归零，不同于普通 PID 移动到 0°：

1. 电机以 `LIFT_HOMING_SPEED`（-50%）功率持续下压
2. 每帧监测编码器角度
3. 若角度持续 0.3s 无变化（堵转 = 已到底），记录当前编码值为零偏移
4. `_lift_zero_offset` 保存此次偏移，此后所有 PID 位置都减去此偏移
5. 每次重新上电或硬重启后需要重新砸底归零

**关键常量**：

| 常量                     | 默认值 | 说明               |
| ------------------------ | :----: | ------------------ |
| `LIFT_HOMING_SPEED`      |  -50   | 归零下压速度（%）  |
| `LIFT_HOMING_STALL_TIME` |  0.3   | 堵转判定等待（秒） |

## 10. 自适应夹爪系统

### 10.1 概述

两个升降臂各搭载一个夹爪舵机：

- M6-INDEX1：一号臂夹取
- M6-INDEX2：二号臂夹取

R2 键触发**二号臂**舵机自适应夹取。使用速度堵转检测判断是否夹到物体，角度硬限位保护机械结构。

### 10.2 操作

| 操作    | 功能             |  LED   |
| ------- | ---------------- | :----: |
| 按 R2   | 启动夹紧（慢速） | `GRP`  |
| 夹到    | 自动停电保持     | `Hld`  |
| 再按 R2 | 释放回全开位 0°  | `OPn`  |
| 超时    | 5s 未夹到停      | `tOut` |
| 超限    | 到达 280° 强制停 | `LIM`  |

### 10.3 检测流程（每帧）

```
1️⃣ 角度 ≥ 280°？ ──是──→ 🚨 强制停电 (LED: LIM)
      │ 否
2️⃣ 启动延迟 0.3s 未过？ ──是──→ 跳过检测
      │ 否
3️⃣ 速度 < 5 rpm？ ──是──→ 堵转=夹到 (LED: Hld)
      │ 否
4️⃣ 超时 5s？ ──是──→ 超时停止 (LED: tOut)
      │ 否
      → 继续夹紧
```

### 10.4 参数

| 参数                   | 默认值 | 说明     |
| ---------------------- | :----: | -------- |
| `GRIP_SPEED_THRESHOLD` | 5 rpm  | 堵转判定 |
| `GRIP_CLOSE_POWER`     |  -25   | 夹紧功率 |
| `GRIP_SETTLE_TIME`     |  0.3s  | 启动延迟 |
| `GRIP_TIMEOUT`         |  5.0s  | 超时     |

> 🚨 铁律：`servo_dir = -1` 写死，0°=全开，负=夹紧，正=撑爆。`SERVO_MAX_ANGLE = 280°` 机械极限。

## 12. 标定模式

### 12.1 进入方式

调试模式下按 **L1+R1** 同时按下 → 进入标定子模式。

### 12.2 功能

标定移动使用 **S 曲线加速 + 左右 PID 补偿**：

- **S 曲线**：sin 加速（0→40%进度）+ 匀速（40%→60%）+ cos 减速（60%→100%）
- **PID 补偿**：M1 和 M2 进度差 → 修正左右速度，保证直走不偏

### 12.3 操作

| 操作            | 说明             |
| --------------- | ---------------- |
| 进入后等待 1 秒 | 自动执行标定移动 |
| 按 N1           | 手动执行         |
| L1+R1           | 退出标定模式     |

### 12.4 校准参数

```python
CAL_TARGET_CM = 20        # 目标直走距离（厘米）
CAL_DEG_PER_CM = 1000/58  # 编码度/厘米
```

修改 `CAL_TARGET_CM` 即可改变标定距离。

> **超时保护**：标定移动超过 `DEBUG_CAL_TIMEOUT = 5.0` 秒未完成则自动停止，防止电机堵转卡死。

## 15. 调参指南

### 15.1 面切换"转不够"

**症状**：L1 换面后实际转角 < 120°

**解决**：增大 `FACE_ROTATE_WHEEL_DEG`

```
新值 = 当前值 × (120° ÷ 实测转角)
```

### 15.2 面切换"转过头"

**症状**：换面后实际转角 > 120°，然后回弹

**解决**：

1. 减小 `FACE_ROTATE_WHEEL_DEG`
2. 或增大 `FACE_ROTATE_PID_KD`（增强阻尼）
3. 或减小 `FACE_ROTATE_MAX_SPEED`（降低冲量）

### 15.3 面切换不丝滑（急刹车）

**症状**：快到位时突然停住，不够顺滑

**解决**：

1. 增大 `FACE_ROTATE_DECEL_ZONE`（提前减速，如 0.30 → 0.50）
2. 减小 `FACE_ROTATE_MIN_SPEED`（末速更低）

### 15.4 面切换太慢

**症状**：旋转耗时长

**解决**：

1. 增大 `FACE_ROTATE_MAX_SPEED`
2. 增大 `FACE_ROTATE_PID_KP`
3. 减小 `FACE_ROTATE_SETTLE_TIME`

### 15.5 面切换超时

**症状**：打印"强制停止"但实际还没转到位

**解决**：增大 `FACE_ROTATE_TIMEOUT`（如 0.6 → 2.0）

### 15.6 遥控太灵敏/太迟钝

**解决**：调整 `STICK_HIGH_EXPO`（指数区幂次）和 `STICK_LOW_PIVOT`（线性区上限）

- 增大 `STICK_HIGH_EXPO` → 低速段更细腻（推荐 1.5~2.0）
- 减小 `STICK_HIGH_EXPO` → 更接近线性（1.0 = 完全线性）
- 增大 `STICK_LOW_PIVOT` → 扩大线性区范围

### 15.7 右摇杆左右反转

**解决**：将 `INVERT_OMEGA` 改为 `True`

### 15.8 前进/后退力度不对称

**症状**：前进和后退速度不一致

**解决**：调整 `VY_BOOST`（默认 1.40，增大=前进更猛，减小=前后平衡）

## 16. 通用编码电机位置 PID

### 16.1 概述

`motor_pos` 系统是一个通用的编码电机位置闭环控制器，适用于 M1~M5 任意编码电机。
与升降臂专用 PID 不同，此系统的 PID 参数可由 GUI 自动程序每步自定义传入。

### 16.2 设计目的

- **解耦底盘与机构**：底盘移动（enc_move）和机构动作（motor_pos）可以并行执行
- **即发即走**：`motor_pos_start()` 启动后立即返回，PID 由 `motor_pos_tick_all()` 后台驱动
- **可定制 PID**：每步可传入不同的 kp/ki/kd，适应不同负载

### 16.3 自动程序用法

```python
('motor_pos', 'M4', 330, 0.35, 0.002, 0.05)
```

此步启动 M4 移动到 330°，使用指定的 PID 参数。启动后立即进入下一步，PID 后台运行。

### 16.4 关键常量

| 常量                    | 默认值 | 说明               |
| ----------------------- | :----: | ------------------ |
| `MOTOR_POS_MAX_SPEED`   |  100   | 最大输出功率 %     |
| `MOTOR_POS_MIN_SPEED`   |   20   | 最小功率 %         |
| `MOTOR_POS_DEADBAND`    |   6    | 到位死区（度）     |
| `MOTOR_POS_SETTLE_TIME` |  0.25  | 稳定确认时间（秒） |
| `MOTOR_POS_TIMEOUT`     |  5.0   | 超时保护（秒）     |
| `MOTOR_POS_DECEL_ZONE`  |  0.35  | 减速区间占比       |

### 16.5 与升降臂 PID 的区别

| 特性       | 升降臂 PID (`lift_pid_*`) | 通用位置 PID (`motor_pos_*`)  |
| ---------- | ------------------------- | ----------------------------- |
| 适用范围   | 仅 M4/M5 升降臂           | M1~M5 任意编码电机            |
| PID 参数   | 全局固定常量              | 每步可自定义                  |
| 方向补偿   | `LIFT_DIR` 自动补偿       | 无内置方向补偿                |
| 编码器符号 | `LIFT_ENCODER_SIGN`       | 直接读取 `get_value("angle")` |
| 触发方式   | 按键（N2/D-pad）          | 自动程序 `motor_pos` 标签     |
