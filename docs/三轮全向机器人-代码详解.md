## 1. 系统架构

### 1.1 主循环结构

```
while True:
    ├── 自动模式 (auto_mode)
    │   ├── 特殊标签步 (encoder_cal / enc_move / enc_rot / enc_stop / spin / delay / motor / dc_motor / servo)
    │   └── 标准运动步 (4元组: 时间 + Vx + Vy + omega)
    │
    ├── 调试模式 (debug_mode)
    │   ├── 标定子模式 (debug_cal_mode)
    │   └── 主调试模式 (编码电机/直流/升降臂/舵机 逐项测试)
    │
    └── 正常模式 (手动遥控)
        ├── 面切换旋转中 → PID tick + 连按叠加
        ├── 摇杆读取 + 按键处理
        ├── 升降臂档位 (D-pad ↑↓ / N3回零)
        ├── 自适应夹爪 (R2 切换 + 每帧速度/角度监测)
        ├── 升降臂 PID tick (每帧)
        ├── 死区 → 指数曲线 → 速度缩放 → 方向校准
        ├── 正面旋转 → 运动学解算 → 电机输出
        └── LED 显示
```

### 1.2 三种模式的优先级

| 优先级 | 模式     | 触发方式 | 说明                             |
| ------ | -------- | -------- | -------------------------------- |
| 最高   | 自动模式 | `+` 键   | 遥控完全禁用，程序结束后自动恢复 |
| 中     | 调试模式 | `≡` 键   | 逐电机测试，遥控禁用             |
| 正常   | 遥控模式 | 默认     | 全功能遥控 + 面切换              |

## 2. 数学基础

### 2.1 三轮全向运动学

```
          前进方向 (+Vy)
               ↑
        M1 ←──┼──→ M2      (前左 M1 @150°, 前右 M2 @30°)
               │
              M3            (尾部 M3 @270°)
```

**逆运动学方程**（输入速度 → 输出电机功率）：

```
M1_power = -0.5·Vx - 0.866·Vy - ω
M2_power = -0.5·Vx + 0.866·Vy - ω
M3_power =  1.0·Vx            - ω
```

其中：

- `Vx`：横向速度（+右, -左）
- `Vy`：纵向速度（+前, -后）
- `ω`：旋转速度（+顺时针, -逆时针）

**关键特性**：当任意电机功率超过 ±100 时，三路等比缩放，保持运动方向不变。

### 2.2 摇杆指数响应曲线

采用 **WPILib 风格** 的指数映射：

```
output = sign(x) × (|x|/100)^exponent × 100
```

| 摇杆推幅 | 线性 (exp=1.0) | 二次 (exp=2.0) | 三次 (exp=3.0) |
| -------- | :------------: | :------------: | :------------: |
| 25%      |      25%       |   **6.25%**    |     1.56%      |
| 50%      |      50%       |    **25%**     |     12.5%      |
| 75%      |      75%       |   **56.25%**   |     42.2%      |
| 100%     |      100%      |      100%      |      100%      |

**效果**：低速段极度细腻（微操精准），高速段满功率爆发。当前使用 `exp=2.0`。

### 2.3 正面旋转矩阵

三个正面本质上是将摇杆坐标系旋转 0° / +120° / -120°：

```
Face 0 (默认):  Vx' =  1.0·Vx + 0.0·Vy    Vy' =  0.0·Vx + 1.0·Vy   (不变)
Face 1 (右切):  Vx' = -0.5·Vx - 0.866·Vy  Vy' =  0.866·Vx - 0.5·Vy (+120°)
Face 2 (左切):  Vx' = -0.5·Vx + 0.866·Vy  Vy' = -0.866·Vx - 0.5·Vy (-120°)
```

预计算为 `FACE_ROTATIONS` 数组，循环中避免重复计算三角函数。

### 2.4 PID 控制器（面切换旋转）

```
omega = Kp·error + Ki·∫error·dt + Kd·d(error)/dt
```

| 参数          | 作用                       | 过大后果       |
| ------------- | -------------------------- | -------------- |
| **Kp** (比例) | 主力响应，误差越大输出越大 | 震荡           |
| **Ki** (积分) | 消除末尾静差               | 超调、积分饱和 |
| **Kd** (微分) | 抑制震荡，预测趋势         | 抖动、噪声放大 |

**积分限幅**：`|integral| ≤ MAX_SPEED / KI`，防止积分饱和（windup）。

### 2.5 余弦减速曲线

接近目标时（误差 < 目标的 DECEL_ZONE%），速度按余弦曲线平滑降速：

```
speed_limit = MIN_SPEED + (MAX_SPEED - MIN_SPEED) × cos(progress × π/2)
```

其中 `progress` 从 0（刚进入减速区）到 1（到达目标）。这条曲线在起点斜率为 0（无缝衔接），终点平滑降到最低速度。

## 3. 遥控操控

### 3.1 摇杆处理流水线

```
原始值 (-100~100)
  → apply_dead_zone()       死区过滤 (|x|<8→0)
  → apply_response_curve()  指数曲线 (exp=2.0)
  → × SPEED_SCALE           全局缩放 (×0.6)
  → INVERT_*                方向校准
  → rotate_velocity()       正面旋转
  → omni_kinematics()       运动学解算
  → motor.set_power()       输出
```

### 3.2 左摇杆 → 全向移动

| 操作 | Lx  | Ly  | 效果     |
| ---- | :-: | :-: | -------- |
| ↑    |  0  |  +  | 前进     |
| ↓    |  0  |  −  | 后退     |
| ←    |  −  |  0  | 左横移   |
| →    |  +  |  0  | 右横移   |
| ↖    |  −  |  +  | 左前斜向 |
| ↗    |  +  |  +  | 右前斜向 |

### 3.3 右摇杆 → 原地自旋

| 操作 | Rx  | 效果 |
| ---- | :-: | ---- |
| ←    |  −  | 左转 |
| →    |  +  | 右转 |

> **注意**：`INVERT_OMEGA = False` 表示右摇杆不做额外取反。如果右摇杆左右反转，将此常量改为 `True`。

### 3.4 死区 (Dead Zone)

摇杆在中位附近有微小抖动（±5 左右）。`DEAD_ZONE = 8` 将这些微小值归零，防止机器人静止时微微抖动。

## 4. 正面切换系统

### 4.1 设计动机

三轮全向机器人有三个"面"（三角形的三条边），默认 M1-M2 边为正面。比赛中需要切换正面以应对不同方向的任务。

### 4.2 工作原理

切换正面不是简单地改一个变量——摇杆坐标系需要**旋转 120°**，使"前进"方向始终对应新正面的法线方向。

```
Face 0 → Face 1: 坐标系旋转 +120°
Face 1 → Face 2: 坐标系旋转 +120°
Face 2 → Face 0: 坐标系旋转 +120°（回到起点）
```

### 4.3 面切换 + 车身旋转

按 L1 时：

1. `face = (face + 1) % 3` —— 逻辑切换
2. `face_rotate_start()` —— 启动 PID 闭环旋转 120°
3. 旋转期间遥控禁用，完成后恢复

### 4.4 连续换面

旋转中再次按 L1 → 叠加一个面（`face_rot_target_deg += FACE_ROTATE_WHEEL_DEG`），重置超时计时。快速按两下 = 一次性转 240°。

## 5. L1 编码器闭环换面

### 5.1 概述

这是整个程序中最复杂的子系统，实现了**编码器反馈 + PID 控制 + 余弦减速**的闭环旋转。

### 5.2 为什么不用时间开环？

时间开环的致命问题：

- 电池电压变化 → 电机转速变化 → 角度不准
- 地面摩擦力不同 → 同样时间转不同角度
- 每次误差累积 → 换几次面后方向完全偏了

编码器闭环**以实际转动的角度为准**，不受上述因素影响。

### 5.3 控制流程

```
face_rotate_start()
  ├── 记录三轮起始编码值
  ├── 设定目标 = FACE_ROTATE_WHEEL_DEG
  ├── 清零 PID 状态
  └── face_rotating = True

每循环 face_rotate_tick():
  ├── 读三轮当前编码 → 取平均增量
  ├── error = 目标 - 当前
  ├── 到位检测 → 稳定确认 → 完成
  ├── PID 计算 omega
  ├── 余弦减速（接近目标时）
  ├── 限幅 + 最小速度兜底
  ├── 方向取反（物理电机方向修正）
  └── omni_kinematics(0, 0, omega) → 输出
```

### 5.4 到位检测 + 稳定确认

不是简单的"误差 < 死区 → 完成"，而是两阶段：

1. **进入死区**：`|error| ≤ FACE_ROTATE_DEADBAND` → 开始计时
2. **稳定确认**：在死区内连续保持 `FACE_ROTATE_SETTLE_TIME` 秒 → 确认真完成

如果中途误差跳出死区 → 重置计时，重新追赶。这避免了"惯性冲过死区后立即判定完成"的误判。

### 5.5 关键常量校准

| 常量                    | 含义                     | 校准方法                       |
| ----------------------- | ------------------------ | ------------------------------ |
| `FACE_ROTATE_WHEEL_DEG` | 120°底盘旋转对应轮子角度 | 设置初值→测实际转角→按比例调整 |

**校准公式**：`新值 = 旧值 × (120° ÷ 实测转角)`

## 6. 自动程序系统

### 6.1 概述

自动程序通过 `AUTO_SEQUENCE` 列表定义，由 `trajectory_planner` GUI 工具生成。按 `+` 键触发，运行期间遥控禁用。

### 6.2 步骤类型

#### 标准运动步（4 元组）

```python
(持续时间_秒, Vx, Vy, omega)
```

- 支持方向和速度的步间线性插值（`AUTO_RAMP_MS`）
- 支持步内加速斜坡（`AUTO_ACCEL_MS`，0→100→0 梯形）

#### 编码器闭环步（enc_move）

```python
('enc_move', total_ticks, vy_power, 0)
```

- 使用 novapi 内置 `move()` 位置闭环
- `total_ticks` = 厘米 × `ENCODER_TICKS_PER_CM`
- **v5.1 优化**：连续 enc_move 不刹停，直接衔接

#### 编码器自旋步（enc_rot）

```python
('enc_rot', total_ticks, 0, omega_power)
```

- 同 enc_move，但用于原地自旋
- 也支持连续衔接

#### 停止缓冲（enc_stop）

```python
('enc_stop', 0, 0, 0)
```

- 短暂停顿，不终止整个序列
- 用于 enc_move 段之间的明确分隔

#### 时间自旋（spin）

```python
('spin', degrees, omega_power)
```

- 时间驱动（非编码器），适用于快速旋转
- `degrees` 为目标旋转角度，`omega_power` 为速度

#### 其他标签

| 标签          | 格式                               | 说明               |
| ------------- | ---------------------------------- | ------------------ |
| `delay`       | `('delay', 秒数)`                  | 纯延时等待         |
| `motor`       | `('motor', 'M1', 功率)`            | 持续转动某编码电机 |
| `dc_motor`    | `('dc_motor', 'DC1', 功率)`        | 持续转动某直流电机 |
| `encoder_cal` | `('encoder_cal', 时长, Vx, Vy, ω)` | GUI 编码器标定     |

### 6.3 步间插值 (AUTO_RAMP_MS)

进入新步骤的前 `AUTO_RAMP_MS` 毫秒内，速度从上一拍的终值**线性插值**到当前拍的目标值。避免速度跳变 → 电流冲击 / 轮子打滑。

```
alpha = elapsed_ms / AUTO_RAMP_MS          (0 → 1)
Vx_out = prev_Vx + (target_Vx - prev_Vx) × alpha
```

### 6.4 步内加速斜坡 (AUTO_ACCEL_MS)

每步内部的功率曲线：**0 → 100% → 0**，呈梯形。

```
         功率
          ↑
    100%  │     ████████
          │   ╱          ╲
      0%  │ ╱              ╲
          └──────────────────→ 时间
          加速段  匀速段  减速段
```

步长不足以容纳完整梯形时（`step_ms ≤ ACCEL_MS × 2`），不启用斜坡。

## 8. 升降臂系统

### 8.1 概述

升降臂使用 M5 编码电机（二号臂），通过 PID 闭环控制到达目标档位。到位后自动停电，依靠机械蜗杆自锁维持位置。

### 8.2 正常模式操作

| 操作    | 功能               |      LED       |
| ------- | ------------------ | :------------: |
| D-pad ↑ | 升一档 L0→L1→L2→L0 | `L0` `L1` `L2` |
| D-pad ↓ | 降一档             | `L0` `L1` `L2` |
| N3      | 回零档 L0（底部）  |      `L0`      |

### 8.3 预设档位

| 档位 | 角度 | 说明         |
| :--: | :--: | ------------ |
|  L0  |  0°  | 底部（零点） |
|  L1  | 330° | 第一档       |
|  L2  | 660° | 第二档       |

### 8.4 PID 控制流程

```
lift_pid_start(目标角度)
  → 每帧 lift_pid_tick():
      ├─ 读 M5 编码器角度 → 计算误差
      ├─ PID 计算功率 (Kp=0.35, Ki=0.002, Kd=0.05)
      ├─ 余弦减速（接近目标时丝滑降速）
      ├─ 到位检测: 误差<6° → 稳定 0.3s → set_power(0) 停电
      └─ 超时 3s → 强制停电
```

> **关键设计**：停电后机械蜗杆自锁维持位置，避免电机持续通电过热。

## 9. 自适应夹爪系统

### 9.1 概述

R2 键触发二号臂舵机（M6-INDEX2）自适应夹取。使用速度堵转检测判断是否夹到物体，角度硬限位保护机械结构。

### 9.2 操作

| 操作    | 功能             |  LED   |
| ------- | ---------------- | :----: |
| 按 R2   | 启动夹紧（慢速） | `GRP`  |
| 夹到    | 自动停电保持     | `Hld`  |
| 再按 R2 | 释放回全开位 0°  | `OPn`  |
| 超时    | 5s 未夹到停      | `tOut` |
| 超限    | 到达 280° 强制停 | `LIM`  |

### 9.3 检测流程（每帧）

```
1️⃣ 角度 ≥ 280°？ ──是──→ 🚨 强制停电 (LED: LIM)
      │ 否
2️⃣ 启动延迟 0.3s 未过？ ──是──→ 跳过检测
      │ 否
3️⃣ 速度 < 5 rpm？ ──是──→ 堵转=夹到 (LED: Hld)
      │ 否
4️⃣ 超时 5s？ ──是──→ 超时停止 (LED: tOut)
      │ 否
      → 继续夹紧
```

### 9.4 参数

| 参数                   | 默认值 | 说明     |
| ---------------------- | :----: | -------- |
| `GRIP_SPEED_THRESHOLD` | 5 rpm  | 堵转判定 |
| `GRIP_CLOSE_POWER`     |  -25   | 夹紧功率 |
| `GRIP_SETTLE_TIME`     |  0.3s  | 启动延迟 |
| `GRIP_TIMEOUT`         |  5.0s  | 超时     |

> 🚨 铁律：`servo_dir = -1` 写死，0°=全开，负=夹紧，正=撑爆。`SERVO_MAX_ANGLE = 280°` 机械极限。

## 11. 标定模式

### 11.1 进入方式

调试模式下按 **L1+R1** 同时按下 → 进入标定子模式。

### 11.2 功能

标定移动使用 **S 曲线加速 + 左右 PID 补偿**：

- **S 曲线**：sin 加速（0→40%进度）+ 匀速（40%→60%）+ cos 减速（60%→100%）
- **PID 补偿**：M1 和 M2 进度差 → 修正左右速度，保证直走不偏

### 11.3 操作

| 操作            | 说明             |
| --------------- | ---------------- |
| 进入后等待 1 秒 | 自动执行标定移动 |
| 按 N1           | 手动执行         |
| L1+R1           | 退出标定模式     |

### 11.4 校准参数

```python
CAL_TARGET_CM = 20        # 目标直走距离（厘米）
CAL_DEG_PER_CM = 1000/58  # 编码度/厘米
```

修改 `CAL_TARGET_CM` 即可改变标定距离。

## 14. 调参指南

### 12.1 面切换"转不够"

**症状**：L1 换面后实际转角 < 120°

**解决**：增大 `FACE_ROTATE_WHEEL_DEG`

```
新值 = 当前值 × (120° ÷ 实测转角)
```

### 12.2 面切换"转过头"

**症状**：换面后实际转角 > 120°，然后回弹

**解决**：

1. 减小 `FACE_ROTATE_WHEEL_DEG`
2. 或增大 `FACE_ROTATE_PID_KD`（增强阻尼）
3. 或减小 `FACE_ROTATE_MAX_SPEED`（降低冲量）

### 12.3 面切换不丝滑（急刹车）

**症状**：快到位时突然停住，不够顺滑

**解决**：

1. 增大 `FACE_ROTATE_DECEL_ZONE`（提前减速，如 0.30 → 0.50）
2. 减小 `FACE_ROTATE_MIN_SPEED`（末速更低）

### 12.4 面切换太慢

**症状**：旋转耗时长

**解决**：

1. 增大 `FACE_ROTATE_MAX_SPEED`
2. 增大 `FACE_ROTATE_PID_KP`
3. 减小 `FACE_ROTATE_SETTLE_TIME`

### 12.5 面切换超时

**症状**：打印"强制停止"但实际还没转到位

**解决**：增大 `FACE_ROTATE_TIMEOUT`（如 0.6 → 2.0）

### 12.6 遥控太灵敏/太迟钝

**解决**：调整 `JOYSTICK_EXPO` 和 `OMEGA_EXPO`

- 增大 → 低速段更细腻（推荐 2.0~2.5）
- 减小 → 更接近线性（1.0 = 完全线性）

### 12.7 右摇杆左右反转

**解决**：将 `INVERT_OMEGA` 改为 `True`
